1 Waar gaat dit over?

Tetris vraagt een grid, vallende stukken en rij-detectie. Je leert een 2D-rooster en het roteren van vormen.

2 Wat leer je?

grid2D-lijstencollisionrotatie

3 Stap voor stap

Stap 1

Maak een leeg speelveld

Een lijst met rijen vormt het bord. 0 betekent leeg.

python
breedte, hoogte = 10, 20
bord = [[0 for _ in range(breedte)] for _ in range(hoogte)]

def toon():
    for rij in bord:
        print("".join("#" if cel else "." for cel in rij))
Stap 2

Plaats een vallend blok

Een T-vorm bestaat uit vier coördinaten. Teken ze in het bord.

python
blok = [(4, 0), (5, 0), (6, 0), (5, 1)]

for x, y in blok:
    bord[y][x] = 1

toon()
Stap 3

Laat het blok zakken en wis rijen

Verschuif het blok omlaag tot het ergens op stuit. Daarna verwijder je volledige rijen.

python
def zakt_naar_beneden(blok):
    while all(y + 1 < hoogte and bord[y + 1][x] == 0 for x, y in blok):
        blok = [(x, y + 1) for x, y in blok]
    for x, y in blok:
        bord[y][x] = 1
    return blok

zakt_naar_beneden(blok)

for rij in range(hoogte):
    if all(bord[rij]):
        bord.pop(rij)
        bord.insert(0, [0] * breedte)

toon()

4 Tips

  • Begin met één soort blok voordat je rotaties toevoegt.
  • Test rij-detectie met een handmatig gevuld bord.
