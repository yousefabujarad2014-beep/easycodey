Boter-kaas-en-eieren

Het 3x3-spel met twee spelers of een computertegenstander.

1 Waar gaat dit over?

Je bouwt een bord van negen vakjes, wisselt beurten af en controleert alle winnende lijnen. Daarna voeg je een simpele computer toe. Dit project leert je goed nadenken over lijsten en indexen.

2 Wat leer je?

listsindexenfunctiesloopsrandom

3 Stap voor stap

Stap 1

Maak het bord en de weergave

Een lijst van negen spaties is genoeg voor het bord. De functie toon_bord() print het in een 3x3-rooster.

python
bord = [" "] * 9

def toon_bord():
    print()
    print(bord[0], "|", bord[1], "|", bord[2])
    print("--+---+--")
    print(bord[3], "|", bord[4], "|", bord[5])
    print("--+---+--")
    print(bord[6], "|", bord[7], "|", bord[8])

toon_bord()
Stap 2

Laat een speler een zet doen

De speler kiest 1 tot 9 en jij rekent dat om naar een index van 0 tot 8. Controleer of het vakje nog leeg is.

python
def zet(speler):
    while True:
        try:
            plek = int(input(f"Speler {speler}, kies 1-9: ")) - 1
        except ValueError:
            print("Vul een getal in.")
            continue

        if 0 <= plek < 9 and bord[plek] == " ":
            bord[plek] = speler
            return
        print("Die plek is niet vrij.")
Stap 3

Controleer of iemand wint

Er zijn acht winnende lijnen: drie rijen, drie kolommen en twee diagonalen. Loop ze allemaal langs en kijk of de drie vakjes gelijk zijn.

python
lijnen = [
    (0, 1, 2), (3, 4, 5), (6, 7, 8),
    (0, 3, 6), (1, 4, 7), (2, 5, 8),
    (0, 4, 8), (2, 4, 6),
]

def winnaar():
    for a, b, c in lijnen:
        if bord[a] == bord[b] == bord[c] != " ":
            return bord[a]
    return None
Stap 4

Wissel beurten af

Gebruik een for-loop van negen beurten. Na elke zet controleer je op winst. De for-else wordt uitgevoerd als de loop niet is gestopt: dan is het gelijkspel.

python
speler = "X"

for beurt in range(9):
    toon_bord()
    zet(speler)

    if winnaar():
        toon_bord()
        print(winnaar(), "heeft gewonnen!")
        break

    speler = "O" if speler == "X" else "X"
else:
    toon_bord()
    print("Gelijkspel!")
Stap 5

Voeg een computer toe

Laat de computer willekeurig een vrij vakje kiezen. Dat is nog niet slim, maar wel een goede eerste stap. Later kun je hem laten blokkeren of winnen.

python
import random

def computer_zet():
    vrije_plekken = [i for i, vak in enumerate(bord) if vak == " "]
    if vrije_plekken:
        bord[random.choice(vrije_plekken)] = "O"

4 Tips

  • Print het bord na elke zet, anders zie je niet wat er gebeurt.
  • Test eerst met twee menselijke spelers voordat je de computer toevoegt.
  • Een slimme computer kijkt eerst of hij kan winnen, daarna of hij moet blokkeren.
