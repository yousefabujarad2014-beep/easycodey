Rekenmachine met venster

🪟 GUI 🎚 Beginner ⏱ 60 min 5 stappen

Bouw een echte rekenmachine met knoppen en een scherm.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je maakt met tkinter een venster met een invoerveld en knoppen. Je leert widgets plaatsen, klikken afhandelen en rekenen met invoer.

2 Wat leer je?

tkintergridlambdafuncties

3 Stap voor stap

Stap 1

Maak het venster

tkinter zit standaard bij Python. Maak eerst een venster met een titel en een invoerveld.

python
import tkinter as tk

venster = tk.Tk()
venster.title("Rekenmachine")

scherm = tk.Entry(venster, font=("Segoe UI", 20), justify="right")
scherm.grid(row=0, column=0, columnspan=4, sticky="nsew", padx=8, pady=8)

venster.mainloop()
Stap 2

Voeg knoppen toe

Een grid met rijen en kolommen houdt de knoppen netjes uitgelijnd.

python
def voeg_in(teken):
    scherm.insert("end", teken)

knoppen = ["7", "8", "9", "/", "4", "5", "6", "*", "1", "2", "3", "-", "0", ".", "=", "+"]

for index, label in enumerate(knoppen):
    rij = index // 4 + 1
    kolom = index % 4
    knop = tk.Button(venster, text=label, font=("Segoe UI", 16),
                     command=lambda t=label: voeg_in(t))
    knop.grid(row=rij, column=kolom, sticky="nsew", padx=4, pady=4)
Stap 3

Bereken het resultaat

eval is hier alleen veilig omdat je zelf de invoer via knoppen beperkt. Controleer de tekens extra.

python
def bereken():
    tekst = scherm.get()
    if not all(teken in "0123456789.+-*/" for teken in tekst):
        return
    try:
        uitkomst = eval(tekst, {"__builtins__": {}}, {})
    except ZeroDivisionError:
        uitkomst = "delen door 0"
    scherm.delete(0, "end")
    scherm.insert(0, str(uitkomst))

# Koppel de = knop aan bereken()
Stap 4

Maak het venster schaalbaar

Met weight krijgen rijen en kolommen dezelfde ruimte.

python
for i in range(4):
    venster.columnconfigure(i, weight=1)

for i in range(1, 6):
    venster.rowconfigure(i, weight=1)
Stap 5

Voeg een wis-knop toe

Een extra knop maakt de rekenmachine bruikbaar.

python
tk.Button(venster, text="C", command=lambda: scherm.delete(0, "end")).grid(
    row=6, column=0, columnspan=4, sticky="nsew", padx=4, pady=4
)

4 Tips

  • Gebruik nooit eval op vrije tekst van een gebruiker.
  • Test ook delen door nul en meerdere punten.
