CSV-analyse

🤖 Data & AI 🎚 Beginner ⏱ 50 min 5 stappen

Lees een CSV en bereken gemiddelden per groep.

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert het csv-module gebruiken en data groeperen. Je bouwt een klein analyserapport zonder pandas.

2 Wat leer je?

csvdictgemiddeldegroeperen

3 Stap voor stap

Stap 1

Lees de CSV

DictReader maakt van elke rij een dictionary.

python
import csv

with open("cijfers.csv", encoding="utf-8", newline="") as bestand:
    rijen = list(csv.DictReader(bestand))

print(rijen[0])
Stap 2

Groepeer per vak

Bewaar de cijfers per vak in een dictionary.

python
from collections import defaultdict

per_vak = defaultdict(list)
for rij in rijen:
    per_vak[rij["vak"]].append(float(rij["cijfer"]))
Stap 3

Bereken het gemiddelde

Deel de som door het aantal.

python
for vak, cijfers in per_vak.items():
    gemiddelde = sum(cijfers) / len(cijfers)
    print(f"{vak}: {gemiddelde:.1f} ({len(cijfers)} cijfers)")
Stap 4

Sorteer het rapport

Toon het hoogste gemiddelde eerst.

python
rapport = [
    (vak, sum(cijfers) / len(cijfers)) for vak, cijfers in per_vak.items()
]
for vak, gemiddelde in sorted(rapport, key=lambda paar: paar[1], reverse=True):
    print(f"{vak:<12} {gemiddelde:.1f}")
Stap 5

Valideer de invoer

Sla rijen met een ongeldig cijfer over.

python
def lees_cijfer(waarde):
    try:
        return float(waarde.replace(",", "."))
    except ValueError:
        return None

4 Tips

  • Open je CSV eerst in een teksteditor en controleer de kolomnamen.
  • Gebruik Decimal als je met geld rekent.
