Flappy Bird

🎮 Games 🎚 Gemiddeld ⏱ 90 min 3 stappen

Laat een vogel door buizen vliegen.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

1 Waar gaat dit over?

Een klein spel met zwaartekracht en buizen. Je leert physics, score en een eenvoudige game loop.

2 Wat leer je?

pygamezwaartekrachtcollisionscore

3 Stap voor stap

Stap 1

Laat de vogel vallen

Zwaartekracht verhoogt de valsnelheid. Een sprong zet de snelheid omlaag.

python
import pygame

pygame.init()
scherm = pygame.display.set_mode((480, 640))
klok = pygame.time.Clock()

vogel = pygame.Rect(100, 300, 34, 34)
snelheid = 0
zwaartekracht = 0.5

while True:
    snelheid += zwaartekracht
    vogel.y += snelheid
    scherm.fill((110, 190, 255))
    pygame.draw.rect(scherm, (255, 210, 60), vogel)
    pygame.display.flip()
    klok.tick(60)
Stap 2

Spring met de spatiebalk

Bij een toetsaanslag krijgt de vogel een negatieve snelheid.

python
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        pygame.quit()
        raise SystemExit
    if event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE:
        snelheid = -8
Stap 3

Voeg buizen en een score toe

Beweeg buizen naar links en tel een punt als de vogel er langs komt.

python
buizen = [pygame.Rect(480, 200, 70, 260)]
score = 0

for buis in buizen:
    buis.x -= 3
    pygame.draw.rect(scherm, (80, 170, 80), buis)

    if vogel.colliderect(buis) or vogel.bottom >= 640:
        print("Game over. Score:", score)
        break

    if not hasattr(buis, "geteld") and buis.right < vogel.left:
        score += 1
        buis.geteld = True

if buizen and buizen[-1].x < 240:
    buizen.append(pygame.Rect(480, 150, 70, 220))

4 Tips

  • Begin zonder buizen en test eerst alleen de sprong.
  • Gebruik een lijst met dictionaries voor buisposities.
