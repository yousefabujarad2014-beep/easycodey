Regelgebaseerde chatbot

Bouw een chatbot die vragen herkent zonder AI-model.

Moet je iets typen? Vraagt dit project om invoer, dan verschijnt bovenaan je scherm een venster met een tekstvak (drie puntjes). Typ daar je antwoord en druk op Enter.

1 Waar gaat dit over?

Je leert intenties herkennen met trefwoorden en antwoorden kiezen. Dit is een goede basis voordat je een taalmodel gebruikt.

2 Wat leer je?

stringsdictintentieschatbot

3 Stap voor stap

Stap 1

Maak intenties

Elke intentie heeft trefwoorden en een antwoord.

python
intenties = [
    {"woorden": ["hallo", "hoi", "hey"], "antwoord": "Hoi! Waar kan ik mee helpen?"},
    {"woorden": ["python", "leren"], "antwoord": "Begin met een klein project, zoals raad het getal."},
    {"woorden": ["weer"], "antwoord": "Ik kan geen live weer ophalen, maar je kunt een weer-API gebruiken."},
]
Stap 2

Herken een intentie

Tel hoeveel trefwoorden in de zin voorkomen.

python
def herken(tekst):
    tekst = tekst.lower()
    beste = None
    beste_score = 0

    for intentie in intenties:
        score = sum(1 for woord in intentie["woorden"] if woord in tekst)
        if score > beste_score:
            beste = intentie
            beste_score = score

    return beste
Stap 3

Antwoord

Val terug op een hulpvaardig standaardantwoord.

python
def antwoord(tekst):
    intentie = herken(tekst)
    if intentie:
        return intentie["antwoord"]
    return "Dat snap ik nog niet. Probeer woorden als python, weer of hallo."
Stap 4

Maak een gesprek

Blijf vragen tot de gebruiker stopt.

python
while True:
    vraag = input("Jij: ").strip()
    if vraag.lower() in {"stop", "exit", "quit"}:
        break
    print("Bot:", antwoord(vraag))
Stap 5

Breid uit

Voeg een onderwerp toe en test of de juiste intentie wint.

python
intenties.append({
    "woorden": ["bedankt", "thanks"],
    "antwoord": "Graag gedaan!",
})

4 Tips

  • Test met zinnen die meerdere intenties raken.
  • Gebruik een lijst met stopwoorden om ruis te verminderen.
