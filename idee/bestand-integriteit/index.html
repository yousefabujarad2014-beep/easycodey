Bestandsintegriteit

🔐 Security 🎚 Gemiddeld ⏱ 45 min 5 stappen

Controleer of een bestand ongewijzigd is met een hash.

1 Waar gaat dit over?

Je berekent een SHA-256-hash van een bestand en vergelijkt die later opnieuw. Zo ontdek je wijzigingen of beschadigde downloads.

2 Wat leer je?

hashlibbestandensha256vergelijken

3 Stap voor stap

Stap 1

Hash een bestand

Lees het bestand in blokken, zodat grote bestanden niet in één keer in het geheugen passen.

python
import hashlib

def bestand_hash(pad):
    hasher = hashlib.sha256()
    with open(pad, "rb") as bestand:
        for blok in iter(lambda: bestand.read(65536), b""):
            hasher.update(blok)
    return hasher.hexdigest()

print(bestand_hash("data.txt"))
Stap 2

Bewaar de hash

Sla de hash op naast de download.

python
with open("data.sha256", "w", encoding="utf-8") as bestand:
    bestand.write(bestand_hash("data.txt"))
Stap 3

Controleer later

Vergelijk de nieuwe hash met de opgeslagen waarde.

python
def controleer(pad, hashbestand):
    verwacht = open(hashbestand, encoding="utf-8").read().strip()
    return bestand_hash(pad) == verwacht

print(controleer("data.txt", "data.sha256"))
Stap 4

Maak een rapport

Toon een duidelijke melding bij een verschil.

python
if controleer("data.txt", "data.sha256"):
    print("Bestand is ongewijzigd.")
else:
    print("Let op: het bestand is veranderd!")
Stap 5

Test met een wijziging

Pas een kopie aan en kijk of de controle faalt.

python
with open("data-kopie.txt", "w", encoding="utf-8") as bestand:
    bestand.write("aangepast")

4 Tips

  • Een hash bewijst integriteit, niet wie het bestand heeft gemaakt.
  • Gebruik een aparte kopie voor je test, niet je originele bestand.
