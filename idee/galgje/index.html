🪢 Galgje

Raad een woord letter voor letter, met een beperkt aantal levens.

Dit is de app-weergave. Speel de demo of kies ⌨ Gebruik dit idee voor alle code en uitleg.

1 Waar gaat dit over?

Bouw het klassieke woordspel. Je leert werken met sets (voor geraden letters), strings doorlopen en een loop die stopt bij winst of verlies. Aan het eind kun je het uitbreiden met een echt tekeningetje in ASCII.

2 Wat leer je?

setsstringswhileinfuncties

3 Stap voor stap

Stap 1

Kies een geheim woord

Zet een paar woorden in een lijst en kies er willekeurig één. Houd de geraden letters bij in een set: elk teken komt daar maar één keer in voor.

python
import random

woorden = ["python", "computer", "programmeren", "internet", "raket"]
woord = random.choice(woorden)
geraden = set()

print("Het woord heeft", len(woord), "letters.")
Stap 2

Toon het woord met streepjes

Met een generator-expressie maak je per letter een streepje of de letter zelf. join() zet er spaties tussen.

python
def toon_woord():
    return " ".join(letter if letter in geraden else "_" for letter in woord)

print(toon_woord())
Stap 3

Vraag om een letter

Controleer of de letter al geraden is. Zo verspil je geen levens aan dezelfde letter. Voeg de letter daarna toe aan de set.

python
letter = input("Raad een letter: ").lower()

if letter in geraden:
    print("Die had je al geraden.")
else:
    geraden.add(letter)
    if letter in woord:
        print("Goed gedaan!")
    else:
        print("Helaas, die letter zit er niet in.")
Stap 4

Speel met levens

Elke foute letter kost een leven. De loop stopt als de levens op zijn of als alle letters geraden zijn. all() controleert of elke letter in de set zit.

python
levens = 6

while levens > 0:
    print()
    print(toon_woord())
    letter = input("Raad een letter: ").lower()

    if letter in geraden:
        print("Die had je al.")
        continue

    geraden.add(letter)

    if letter in woord:
        print("Goed!")
    else:
        levens -= 1
        print("Mis! Levens over:", levens)

    if all(l in geraden for l in woord):
        print("🎉 Gewonnen! Het woord was:", woord)
        break
else:
    print("Helaas, je levens zijn op. Het woord was:", woord)

4 Tips

  • Test met een kort woord zoals 'kat' voordat je lange woorden gebruikt.
  • Teken de galg met een lijst strings en print de juiste fase.
  • Voeg een categorie-hint toe, bijvoorbeeld 'dier' of 'technologie'.
