Lokale poortscanner

🔐 Security 🎚 Gevorderd ⏱ 90 min 5 stappen

Ontdek welke poorten op je eigen computer openstaan.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert sockets en netwerkpoorten. Je test uitsluitend je eigen machine, met een korte time-out en duidelijke waarschuwing.

2 Wat leer je?

socketnetwerkpoortentime-out

3 Stap voor stap

Stap 1

Test één poort

connect_ex geeft 0 als de verbinding lukt.

python
import socket

def is_open(host, poort, time-out=0.3):
    with socket.socket() as sock:
        sock.settimeout(time-out)
        return sock.connect_ex((host, poort)) == 0

print(is_open("127.0.0.1", 80))
Stap 2

Scan een kleine lijst

Beperk het aantal poorten zodat je niet onbedoeld veel verkeer maakt.

python
poorten = [22, 80, 443, 3000, 4173, 5000, 8000]

for poort in poorten:
    if is_open("127.0.0.1", poort):
        print(f"Poort {poort} is open")
Stap 3

Gebruik een time-out

Zonder time-out kan een scan lang blijven hangen.

python
sock.settimeout(0.3)
Stap 4

Maak een rapport

Sla de resultaten overzichtelijk op.

python
import json

resultaat = {"host": "127.0.0.1", "open": []}
for poort in poorten:
    if is_open("127.0.0.1", poort):
        resultaat["open"].append(poort)

print(json.dumps(resultaat, indent=2))
Stap 5

Voeg een waarschuwing toe

Scannen mag alleen op systemen die je bezit of waarvoor je toestemming hebt.

python
print("Scan alleen je eigen computer of een systeem met expliciete toestemming.")

4 Tips

  • Scan nooit willekeurige websites of netwerken.
  • Een firewall kan een open poort alsnog blokkeren.
