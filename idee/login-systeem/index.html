1 Waar gaat dit over?

Je leert wachtwoorden hashen met een salt, sessies gebruiken en controleren of iemand ingelogd is. Je slaat nooit platte wachtwoorden op.

2 Wat leer je?

3 Stap voor stap

Stap 1

Hash een wachtwoord

Een salt maakt elke hash uniek, ook bij hetzelfde wachtwoord.

python
import hashlib
import secrets

def hash_wachtwoord(wachtwoord, salt=None):
    salt = salt or secrets.token_hex(16)
    digest = hashlib.pbkdf2_hmac(
        "sha256", wachtwoord.encode(), salt.encode(), 200_000
    ).hex()
    return f"{salt}${digest}"
Stap 2

Controleer een wachtwoord

Hash de invoer opnieuw met de opgeslagen salt en vergelijk.

python
def controleer(wachtwoord, opgeslagen):
    salt, digest = opgeslagen.split("$")
    nieuw = hashlib.pbkdf2_hmac(
        "sha256", wachtwoord.encode(), salt.encode(), 200_000
    ).hex()
    return secrets.compare_digest(nieuw, digest)
Stap 3

Log de gebruiker in

Bewaar alleen een gebruikersnaam in de sessie, nooit het wachtwoord.

python
from flask import session, redirect

@app.post("/login")
def login():
    naam = request.form.get("naam", "")
    wachtwoord = request.form.get("wachtwoord", "")
    gebruiker = gebruikers.get(naam)

    if gebruiker and controleer(wachtwoord, gebruiker["hash"]):
        session["gebruiker"] = naam
        return redirect("/dashboard")

    return "Onjuiste gegevens", 401
Stap 4

Bescherm een pagina

Controleer de sessie voordat je privé-inhoud toont.

python
@app.get("/dashboard")
def dashboard():
    if "gebruiker" not in session:
        return redirect("/")
    return f"Welkom, {session['gebruiker']}"
