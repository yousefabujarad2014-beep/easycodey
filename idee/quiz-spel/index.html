Quizspel

🎮 Games 🎚 Beginner ⏱ 45 min 5 stappen

Stel meerkeuzevragen, houd de score bij en voeg zelf vragen toe.

1 Waar gaat dit over?

Een quiz met vragen als woordenboeken in een lijst. Je leert hoe je gestructureerde data gebruikt en hoe je gebruikersinvoer omzet naar een antwoord. Aan het eind heb je een sjabloon waarmee je elke quiz kunt maken.

2 Wat leer je?

list van dictsenumerate()for-loopinput()score

3 Stap voor stap

Stap 1

Zet je vragen in een lijst

Elke vraag is een woordenboek met de vraag, de opties en het juiste antwoord. Het juiste antwoord is de index van de optie, beginnend bij 0.

python
vragen = [
    {
        "vraag": "Wat doet print() in Python?",
        "opties": ["Rekent iets uit", "Toont tekst op het scherm", "Slaat een bestand op"],
        "antwoord": 1,
    },
    {
        "vraag": "Welk type is 3.14?",
        "opties": ["int", "str", "float"],
        "antwoord": 2,
    },
]
Stap 2

Toon een vraag met genummerde opties

Met enumerate() zet je een nummer voor elke optie. De gebruiker kiest 1, 2 of 3.

python
for vraag in vragen:
    print()
    print(vraag["vraag"])

    for nummer, optie in enumerate(vraag["opties"], start=1):
        print(nummer, "-", optie)

    keuze = int(input("Jouw antwoord: ")) - 1
Stap 3

Controleer het antwoord en tel de score

Vergelijk de keuze met de opgeslagen index. Geef bij een fout antwoord meteen het juiste antwoord, dat leert het meest.

python
score = 0

for vraag in vragen:
    print()
    print(vraag["vraag"])

    for nummer, optie in enumerate(vraag["opties"], start=1):
        print(nummer, "-", optie)

    keuze = int(input("Jouw antwoord: ")) - 1

    if keuze == vraag["antwoord"]:
        print("Goed!")
        score += 1
    else:
        juiste = vraag["opties"][vraag["antwoord"]]
        print("Helaas. Het juiste antwoord is:", juiste)
Stap 4

Toon de eindscore

Bereken het percentage en sluit af met een passende boodschap. Door de score te delen door het aantal vragen krijg je een cijfer.

python
aantal = len(vragen)
percentage = score / aantal * 100

print()
print(f"Je score: {score} van {aantal} ({percentage:.0f}%)")

if percentage == 100:
    print("Perfect! 🏆")
elif percentage >= 70:
    print("Netjes gedaan!")
else:
    print("Blijf oefenen, je komt er wel.")
Stap 5

Hussel de vragen en breid uit

Met random.shuffle() krijgt elke speler een andere volgorde. Voeg daarna je eigen vragen toe; de code verandert niet mee.

python
import random

random.shuffle(vragen)

# Nieuwe vraag toevoegen:
vragen.append({
    "vraag": "Waar begint een Python-lijst mee te tellen?",
    "opties": ["0", "1", "Altijd willekeurig"],
    "antwoord": 0,
})

4 Tips

  • Hussel de opties niet zomaar, tenzij je ook het juiste antwoord bijwerkt.
  • Vraag om een getal en vang fouten op met try/except.
  • Bewaar je vragen in een JSON-bestand als je meerdere quizzen wilt.
