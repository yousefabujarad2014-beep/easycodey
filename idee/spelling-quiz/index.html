Spellingquiz

🎓 Onderwijs 🎚 Beginner ⏱ 50 min 5 stappen

Oefen spelling met meerkeuzevragen.

1 Waar gaat dit over?

Je leert een quiz bouwen met lijsten en dictionaries. Je voegt uitleg toe, zodat een fout antwoord meteen een leermoment wordt.

2 Wat leer je?

lijstendictquizspelling

3 Stap voor stap

Stap 1

Maak de vragen

Bewaar het juiste woord en twee afleiders.

python
vragen = [
    {"goed": "gebeurt", "fout": ["gebeurd", "gebeurt niet"], "uitleg": "Tegenwoordige tijd: gebeurt."},
    {"goed": "cadeau", "fout": ["kadeau", "cado"], "uitleg": "Cadeau schrijf je met een c."},
]
Stap 2

Stel de vraag

Schud de opties en toon ze met letters.

python
import random

for vraag in vragen:
    opties = [vraag["goed"], *vraag["fout"]]
    random.shuffle(opties)
    print("Kies het juiste woord:")
    for letter, optie in zip("ABC", opties):
        print(f"{letter}. {optie}")
Stap 3

Controleer het antwoord

Vergelijk de gekozen letter met het juiste woord.

python
keuze = input("Antwoord (A/B/C): ").strip().upper()
gekozen = opties["ABC".index(keuze)]
if gekozen == vraag["goed"]:
    print("Goed!")
else:
    print(f"Niet goed. {vraag['uitleg']}")
Stap 4

Houd de score bij

Tel de juiste antwoorden en toon een eindscore.

python
score = 0
# In de lus:
if gekozen == vraag["goed"]:
    score += 1
print(f"Score: {score}/{len(vragen)}")
Stap 5

Lees vragen uit een bestand

Zo kun je de quiz uitbreiden zonder code te wijzigen.

python
import json
from pathlib import Path

vragen = json.loads(Path("spelling.json").read_text(encoding="utf-8"))

4 Tips

  • Gebruik verzonnen woorden of woorden uit je eigen lesstof.
  • Toon de uitleg altijd, ook bij een goed antwoord.
