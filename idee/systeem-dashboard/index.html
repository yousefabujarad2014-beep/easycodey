Systeemdashboard

🪟 GUI 🎚 Gevorderd ⏱ 2 uur 5 stappen

Toon live je CPU, geheugen en schijfgebruik.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert psutil gebruiken en een dashboard bouwen dat zichzelf elke seconde ververst. Je oefent met metingen en nette visualisaties.

2 Wat leer je?

psutiltkintermetingenafter

3 Stap voor stap

Stap 1

Installeer psutil

psutil leest systeeminformatie op Windows, macOS en Linux.

python
# pip install psutil
import psutil
Stap 2

Lees de metingen

Vraag CPU en geheugen op en maak ze leesbaar.

python
def metingen():
    cpu = psutil.cpu_percent(interval=None)
    geheugen = psutil.virtual_memory()
    schijf = psutil.disk_usage("/")
    return {
        "cpu": cpu,
        "ram": geheugen.percent,
        "schijf": schijf.percent,
    }
Stap 3

Bouw de labels

Elke meting krijgt een label en een voortgangsbalk.

python
import tkinter as tk
from tkinter import ttk

venster = tk.Tk()
venster.title("Systeem")

labels = {}
balken = {}

for rij, naam in enumerate(["cpu", "ram", "schijf"]):
    tk.Label(venster, text=naam.upper()).grid(row=rij, column=0, padx=10, pady=6, sticky="w")
    balk = ttk.Progressbar(venster, length=260, maximum=100)
    balk.grid(row=rij, column=1, padx=10)
    label = tk.Label(venster, text="0%")
    label.grid(row=rij, column=2, padx=10)
    labels[naam] = label
    balken[naam] = balk
Stap 4

Ververs elke seconde

after() houdt de GUI responsief.

python
def update():
    data = metingen()
    for naam, waarde in data.items():
        balken[naam]["value"] = waarde
        labels[naam].config(text=f"{waarde:.0f}%")
    venster.after(1000, update)

update()
Stap 5

Maak een waarschuwing

Kleur rood boven 85 procent.

python
def update():
    data = metingen()
    for naam, waarde in data.items():
        balken[naam]["value"] = waarde
        labels[naam].config(text=f"{waarde:.0f}%",
                            fg="#e11d48" if waarde > 85 else "#15150f")
    venster.after(1000, update)

4 Tips

  • Gebruik interval=None alleen na de eerste meting; anders krijg je 0.
  • Test op je eigen computer, niet op een gedeelde server.
