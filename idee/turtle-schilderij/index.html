Turtle-schilderij

🎨 Kunst & Creatief 🎚 Beginner ⏱ 45 min 5 stappen

Laat een schildpad een kleurrijk kunstwerk tekenen.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert turtle gebruiken, lussen combineren en kleuren kiezen. Kleine veranderingen in de hoek geven compleet andere kunst.

2 Wat leer je?

turtlelussenkleurenrandom

3 Stap voor stap

Stap 1

Start turtle

Turtle opent een tekenvenster en tekent met een pen.

python
import turtle

turtle.bgcolor("#15150f")
turtle.pensize(2)
turtle.speed(0)
Stap 2

Teken een spiraal

Een lus met een steeds grotere stap maakt een spiraal.

python
kleuren = ["#ff6b4a", "#ffd43b", "#1f5eff", "#0f9d58", "#a21caf"]

for i in range(180):
    turtle.pencolor(kleuren[i % len(kleuren)])
    turtle.forward(i * 2)
    turtle.right(91)
Stap 3

Voeg willekeur toe

Random maakt elk kunstwerk uniek.

python
import random

for _ in range(60):
    turtle.pencolor(random.choice(kleuren))
    turtle.forward(random.randint(20, 120))
    turtle.right(random.choice([45, 60, 90, 120]))
Stap 4

Bewaar het resultaat

Sla je kunstwerk op als afbeelding.

python
turtle.done()
Stap 5

Experimenteer met kleuren

Gebruik een eigen palet in plaats van de standaardkleuren.

python
palet = ["#f7f5ef", "#ff6b4a", "#ffd43b", "#0ea5a4"]
for i in range(120):
    turtle.pencolor(palet[i % len(palet)])
    turtle.circle(40 + i)
    turtle.right(24)

4 Tips

  • Zet de snelheid op 0 voor grote tekeningen.
  • Bewaar tussenversies met een screenshot voordat je verder experimenteert.
