🎨 Kleuren groeperen met k-means

Haal de belangrijkste kleuren uit een foto.

Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Je leert k-means stap voor stap: punten toewijzen, gemiddelden berekenen en herhalen. Je gebruikt alleen Python en Pillow.

2 Wat leer je?

k-meansclusteringpillowwiskunde

3 Stap voor stap

Stap 1

Lees de pixels

Verklein de foto zodat het algoritme snel blijft.

python
from PIL import Image

foto = Image.open("foto.jpg").convert("RGB")
foto.thumbnail((120, 120))
pixels = list(foto.getdata())
print(len(pixels))
Stap 2

Kies startpunten

Kies willekeurige pixels als beginnende clusters.

python
import random

def afstand(a, b):
    return sum((x - y) ** 2 for x, y in zip(a, b))

centra = random.sample(pixels, 5)
Stap 3

Wijs pixels toe

Elke pixel hoort bij het dichtstbijzijnde centrum.

python
def wijs_toe(pixels, centra):
    groepen = [[] for _ in centra]
    for pixel in pixels:
        index = min(range(len(centra)), key=lambda i: afstand(pixel, centra[i]))
        groepen[index].append(pixel)
    return groepen
Stap 4

Bereken nieuwe centra

Het gemiddelde van een groep wordt het nieuwe centrum.

python
def nieuwe_centra(groepen):
    resultaat = []
    for groep in groepen:
        if not groep:
            resultaat.append(random.choice(pixels))
            continue
        resultaat.append(tuple(sum(kanaal) // len(groep) for kanaal in zip(*groep)))
    return resultaat
Stap 5

Herhaal en toon

Na enkele rondes krijg je de dominante kleuren.

python
for _ in range(8):
    groepen = wijs_toe(pixels, centra)
    centra = nieuwe_centra(groepen)

for kleur in centra:
    print("#{:02x}{:02x}{:02x}".format(*kleur))

4 Tips

  • Gebruik een kleine afbeelding; k-means is rekenintensief.
  • Vaste random seeds maken je resultaat reproduceerbaar.
