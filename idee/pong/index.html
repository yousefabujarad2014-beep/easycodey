🏓 Pong met pygame

De retro tennisklassieker met een computertegenstander.

Dit is de app-weergave. Speel de demo of kies ⌨ Gebruik dit idee voor alle code en uitleg.

1 Waar gaat dit over?

Pong is simpel maar verrassend leerzaam: je werkt met rechthoeken, snelheden, botsingen en een tegenstander die de bal volgt. Perfect als je Snake onder de knie hebt.

2 Wat leer je?

pygame.Rectcollisionssnelheidgame loopAI

3 Stap voor stap

Stap 1

Zet het speelveld klaar

Met pygame.Rect maak je rechthoeken voor de twee peddels en de bal. Een Rect heeft handige eigenschappen zoals top, bottom en colliderect().

python
import pygame

pygame.init()

WIDTH, HEIGHT = 800, 500
scherm = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Pong")
klok = pygame.time.Clock()

speler = pygame.Rect(30, 200, 14, 100)
computer = pygame.Rect(WIDTH - 44, 200, 14, 100)
bal = pygame.Rect(WIDTH // 2, HEIGHT // 2, 14, 14)
bal_snelheid = [4, 3]
Stap 2

Beweeg je peddel

Met W en S bestuur je de linkse peddel. Controleer de randen zodat de peddel niet uit het scherm verdwijnt.

python
while True:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            pygame.quit()
            raise SystemExit

    toetsen = pygame.key.get_pressed()

    if toetsen[pygame.K_w] and speler.top > 0:
        speler.y -= 6
    if toetsen[pygame.K_s] and speler.bottom < HEIGHT:
        speler.y += 6
Stap 3

Laat de bal stuiteren

De bal beweegt elke frame met zijn snelheid. Tegen de boven- of onderkant klapt de verticale snelheid om. Raakt hij een peddel, dan klapt de horizontale snelheid om.

python
    bal.x += bal_snelheid[0]
    bal.y += bal_snelheid[1]

    if bal.top <= 0 or bal.bottom >= HEIGHT:
        bal_snelheid[1] *= -1

    if bal.colliderect(speler) or bal.colliderect(computer):
        bal_snelheid[0] *= -1
Stap 4

Tel punten en reset de bal

Als de bal links of rechts uit het scherm gaat, krijgt de ander een punt. Zet de bal daarna weer in het midden.

python
    if bal.left <= 0 or bal.right >= WIDTH:
        bal.center = (WIDTH // 2, HEIGHT // 2)
        bal_snelheid = [4, 3]

    scherm.fill((12, 12, 16))
    pygame.draw.rect(scherm, (109, 141, 255), speler)
    pygame.draw.rect(scherm, (255, 107, 74), computer)
    pygame.draw.rect(scherm, (244, 242, 234), bal)

    pygame.display.flip()
    klok.tick(60)
Stap 5

Laat de computer spelen

De computerpeddel volgt de bal met een vaste snelheid. Zo is hij niet onverslaanbaar, maar doet hij wel mee.

python
    if computer.centery < bal.centery:
        computer.y += 4
    elif computer.centery > bal.centery:
        computer.y -= 4

    computer.clamp_ip(pygame.Rect(0, 0, WIDTH, HEIGHT))

4 Tips

  • Houd de bal net iets langzamer dan de peddels, anders is het spel niet leuk.
  • Voeg een scorebord toe met pygame.font.SysFont().
  • Met pijltjes in plaats van W/S kun je ook met twee spelers spelen.
