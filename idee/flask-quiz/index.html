🧠 Online quiz

Stel vragen via de browser en houd de score bij.

Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Je combineert een vragenlijst, een POST-formulier en een sessie. Je leert state bewaren tussen requests.

2 Wat leer je?

flasksessiesformsscore

3 Stap voor stap

Stap 1

Maak de vragen

Bewaar vraag, opties en het juiste antwoord.

python
vragen = [
    {"vraag": "Wat doet print()?", "antwoord": "tekst tonen"},
    {"vraag": "Welk type is 3.14?", "antwoord": "float"},
]
Stap 2

Toon één vraag

Gebruik de sessie om de huidige vraag bij te houden.

python
@app.get("/")
def quiz():
    nummer = session.get("nummer", 0)
    if nummer >= len(vragen):
        return f"Klaar! Score: {session.get('score', 0)}"

    vraag = vragen[nummer]
    return f"""
      <p>{vraag['vraag']}</p>
      <form method="post">
        <input name="antwoord" required>
        <button>Antwoord</button>
      </form>
    """
Stap 3

Controleer het antwoord

Vergelijk zonder hoofdletters en spaties en werk de score bij.

python
@app.post("/")
def antwoord():
    nummer = session.get("nummer", 0)
    gegeven = request.form.get("antwoord", "").strip().lower()
    juist = vragen[nummer]["antwoord"].lower()

    if gegeven == juist:
        session["score"] = session.get("score", 0) + 1

    session["nummer"] = nummer + 1
    return redirect("/")
Stap 4

Start opnieuw

Een reset-route maakt de quiz speelbaar voor de volgende gebruiker.

python
@app.get("/reset")
def reset():
    session.clear()
    return redirect("/")

4 Tips

  • Toon na elk antwoord of het goed was.
  • Voeg meerkeuzevragen toe met radio buttons.
