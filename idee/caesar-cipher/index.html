🏛️ Caesar-vercijfering

Vercijfer en ontsleutel tekst met een verschuiving.

Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Je leert hoe klassieke encryptie werkt en waarom een vaste verschuiving niet veilig is. Je oefent met strings, ord() en chr().

2 Wat leer je?

stringsordchrencryptie

3 Stap voor stap

Stap 1

Verschuif één letter

ord() geeft de lettercode en chr() maakt er weer een letter van.

python
def verschuif(letter, aantal):
    if letter.isalpha():
        basis = ord("a") if letter.islower() else ord("A")
        return chr((ord(letter) - basis + aantal) % 26 + basis)
    return letter

print(verschuif("a", 3))
Stap 2

Vercijfer een hele tekst

Pas de verschuiving toe op elke letter.

python
def vercijfer(tekst, aantal):
    return "".join(verschuif(letter, aantal) for letter in tekst)

print(vercijfer("hallo wereld", 3))
Stap 3

Ontsleutel met dezelfde functie

Terugdraaien is verschuiven met het tegenovergestelde aantal.

python
def ontsleutel(tekst, aantal):
    return vercijfer(tekst, -aantal)

print(ontsleutel("kdoor zhuhog", 3))
Stap 4

Probeer alle sleutels

Met 26 mogelijkheden kun je een onbekende tekst brute-forcen.

python
for sleutel in range(26):
    print(sleutel, vercijfer("kdoor", -sleutel))
Stap 5

Voeg cijfers en leestekens toe

Alleen letters verschuiven; de rest blijft staan.

python
print(vercijfer("Python 3 is leuk!", 5))

4 Tips

  • Gebruik deze techniek alleen om te leren, niet voor echte geheimen.
  • Test met hoofdletters en spaties.
