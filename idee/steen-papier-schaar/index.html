Steen, papier, schaar

🎮 Games 🎚 Beginner ⏱ 40 min 5 stappen

Speel tegen de computer en houd de score bij over meerdere rondes.

1 Waar gaat dit over?

Een klassieker die je leert werken met lijsten, willekeurige keuzes en een woordenboek als spelregel. Je bouwt het uit tot een wedstrijd van vijf rondes met een scorebord.

2 Wat leer je?

listsrandom.choice()dictfunctiesfor-loop

3 Stap voor stap

Stap 1

Laat de computer kiezen

Zet de drie opties in een lijst en laat random.choice() eentje kiezen. Zo hoef je geen lange if-keten te schrijven.

python
import random

keuzes = ["steen", "papier", "schaar"]
computer = random.choice(keuzes)

print("De computer koos:", computer)
Stap 2

Vraag de speler om een keuze

lower() maakt van 'Steen' netjes 'steen'. Controleer daarna of de invoer echt in de lijst staat, anders kan de speler vals spelen.

python
speler = input("steen, papier of schaar? ").lower()

if speler not in keuzes:
    print("Kies precies een van de drie opties.")
else:
    print("Jij koos:", speler)
Stap 3

Bepaal wie wint

Een woordenboek legt vast wat wat verslaat. Zo is de spelregel één regel code in plaats van zes losse vergelijkingen.

python
verslaat = {"steen": "schaar", "schaar": "papier", "papier": "steen"}

if speler == computer:
    print("Gelijkspel")
elif verslaat[speler] == computer:
    print("Jij wint!")
else:
    print("De computer wint!")
Stap 4

Speel vijf rondes met een score

Stop de spelronde in een functie en roep die vijf keer aan. De scores houd je bij in een woordenboek buiten de functie.

python
scores = {"jij": 0, "computer": 0}

def speel_ronde():
    speler = input("steen, papier of schaar? ").lower()
    computer = random.choice(keuzes)

    if speler not in keuzes:
        print("Ongeldige keuze, deze ronde telt niet.")
        return

    print("Computer:", computer)

    if speler == computer:
        print("Gelijkspel")
    elif verslaat[speler] == computer:
        print("Jij wint deze ronde!")
        scores["jij"] += 1
    else:
        print("Computer wint deze ronde!")
        scores["computer"] += 1

for ronde in range(5):
    print()
    print("Ronde", ronde + 1)
    speel_ronde()
Stap 5

Maak de uitslag af

Na de loop vergelijk je de scores en print je de winnaar. Dit is ook een mooi moment om de tussenstand na elke ronde te tonen.

python
print()
print("Eindstand")
print("Jij:", scores["jij"])
print("Computer:", scores["computer"])

if scores["jij"] > scores["computer"]:
    print("🏆 Jij bent de winnaar!")
elif scores["jij"] < scores["computer"]:
    print("De computer wint.")
else:
    print("Gelijk spel!")

4 Tips

  • Laat de computer niet met zichzelf spelen tijdens het testen: print de keuze altijd.
  • Voeg 'lizard' en 'spock' toe voor een uitgebreidere versie.
  • Bewaar de scores in een JSON-bestand als je een competitie wilt.
