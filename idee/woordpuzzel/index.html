1 Waar gaat dit over?

Je leert strings vergelijken en feedback geven per letter. Je bouwt een Wordle-achtig spel in de terminal.

2 Wat leer je?

stringslussenfeedbackspel

3 Stap voor stap

Stap 1

Kies een geheim woord

Gebruik een vaste lijst met woorden van vijf letters.

python
import random

woorden = ["appel", "fiets", "school", "tafel", "water"]
geheim = random.choice(woorden)
Stap 2

Geef feedback per letter

Groen is goed op de juiste plek, geel bestaat maar staat elders.

python
def feedback(gok, geheim):
    uitslag = []
    for index, letter in enumerate(gok):
        if letter == geheim[index]:
            uitslag.append("🟩")
        elif letter in geheim:
            uitslag.append("🟨")
        else:
            uitslag.append("⬜")
    return "".join(uitslag)
Stap 3

Speel het spel

Geef de speler zes pogingen.

python
for poging in range(6):
    gok = input("Raad een woord van 5 letters: ").lower().strip()
    if len(gok) != 5:
        print("Gebruik precies 5 letters.")
        continue
    print(feedback(gok, geheim))
    if gok == geheim:
        print("Geraden!")
        break
else:
    print("Helaas, het woord was", geheim)
