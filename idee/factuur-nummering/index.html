Factuurnummers maken

⚙️ Automatisering 🎚 Beginner ⏱ 40 min 5 stappen

Genereer oplopende factuurnummers zonder dubbele nummers.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

1 Waar gaat dit over?

Je leert een teller in een bestand bewaren en nette nummers formatteren. Dit is een kleine maar nuttige administratietool.

2 Wat leer je?

bestandentellersformatterenadministratie

3 Stap voor stap

Stap 1

Lees het laatste nummer

Begin bij 1 als het bestand nog niet bestaat.

python
from pathlib import Path

TELLER = Path("factuur-teller.txt")

def laatste_nummer():
    if not TELLER.exists():
        return 0
    return int(TELLER.read_text().strip() or "0")
Stap 2

Maak een nieuw nummer

Verhoog de teller en schrijf hem direct terug.

python
def nieuw_nummer():
    nummer = laatste_nummer() + 1
    TELLER.write_text(str(nummer), encoding="utf-8")
    return f"F{nummer:05d}"
Stap 3

Toon het resultaat

Test of de nummers netjes oplopen.

python
print(nieuw_nummer())
print(nieuw_nummer())
print(nieuw_nummer())
Stap 4

Voeg een jaartal toe

Veel administraties gebruiken een jaartal in het nummer.

python
from datetime import date

def nieuw_jaarnummer():
    nummer = laatste_nummer() + 1
    TELLER.write_text(str(nummer), encoding="utf-8")
    return f"{date.today().year}-{nummer:04d}"

Maak een back-up

Kopieer de teller voordat je hem voor echt gebruikt.
