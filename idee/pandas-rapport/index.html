🐼 Dataframe-rapport

Analyseer een dataset met pandas.

Dit is de app-weergave. Speel de demo of kies ⌨ Gebruik dit idee voor alle code en uitleg.

1 Waar gaat dit over?

Je leert een DataFrame laden, kolommen selecteren, groeperen en sorteren. Dit is de snelste manier om grote tabellen te begrijpen.

2 Wat leer je?

pandasdataframegroeperenrapport

3 Stap voor stap

Stap 1

Laad de data

Lees een CSV direct in een DataFrame.

python
# pip install pandas
import pandas as pd

df = pd.read_csv("verkopen.csv")
print(df.head())
Stap 2

Bekijk de structuur

Controleer kolommen, types en ontbrekende waarden.

python
print(df.info())
print(df.describe())
print(df.isna().sum())
Stap 3

Maak een nieuwe kolom

Bereken omzet uit aantal en prijs.

python
df["omzet"] = df["aantal"] * df["prijs"]
Stap 4

Groepeer en sorteer

Een groupby geeft totalen per product.

python
per_product = df.groupby("product")["omzet"].sum().sort_values(ascending=False)
print(per_product)
Stap 5

Schrijf een rapport

Sla het resultaat op als CSV.

python
per_product.to_csv("omzet-per-product.csv")
print("Klaar: omzet-per-product.csv")

4 Tips

  • Controleer altijd of bedragen in dezelfde valuta staan.
  • Gebruik een kopie van je data bij het toevoegen van kolommen.
