📏 Eenheden omrekenen

Reken kilometers, kilo's en liters om.

Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Je leert een dictionary met factoren gebruiken en invoer valideren. Je bouwt een converter die met één regel code nieuwe eenheden kan krijgen.

2 Wat leer je?

dictfloatsvalidatiewiskunde

3 Stap voor stap

Stap 1

Bepaal de factoren

Alles wordt eerst omgerekend naar de basiseenheid.

python
FACTOREN = {
    "km": 1000,
    "m": 1,
    "cm": 0.01,
    "mm": 0.001,
}
Stap 2

Reken om

Van bron naar basis en daarna naar doel.

python
def omrekenen(waarde, van, naar):
    if van not in FACTOREN or naar not in FACTOREN:
        raise ValueError("Onbekende eenheid")
    return waarde * FACTOREN[van] / FACTOREN[naar]

print(omrekenen(2.5, "km", "m"))
Stap 3

Vraag de gebruiker om invoer

Vang fouten op en toon een duidelijke melding.

python
try:
    waarde = float(input("Waarde: ").replace(",", "."))
    van = input("Van (km/m/cm/mm): ").strip()
    naar = input("Naar (km/m/cm/mm): ").strip()
    print(f"{waarde} {van} = {omrekenen(waarde, van, naar)} {naar}")
except ValueError as fout:
    print("Fout:", fout)
Stap 4

Voeg gewicht toe

Gebruik een tweede dictionary of een voorvoegsel.

python
GEWICHT = {"kg": 1000, "g": 1, "mg": 0.001}

def gewicht_omrekenen(waarde, van, naar):
    return waarde * GEWICHT[van] / GEWICHT[naar]
Stap 5

Maak een tabel

Toon meerdere conversies in één keer.

python
for eenheid in ("m", "cm", "mm"):
    print(f"1 km = {omrekenen(1, 'km', eenheid):.0f} {eenheid}")

4 Tips

  • Gebruik punt als decimaalteken in je berekening.
  • Test met nul en met negatieve waarden.
