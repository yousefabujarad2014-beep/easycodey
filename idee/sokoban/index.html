3 Stap voor stap

Stap 1

Maak een level

Een string met tekens is makkelijk aan te passen.

level = [
    "#######",

    "# $ $ #",
    "#  @  #",
    "#######",
]
# # muur, . doel, $ kist, @ speler
Stap 2

Zoek de speler

Bewaar de positie als rij en kolom.

python
def vind_speler(bord):
    for y, rij in enumerate(bord):
        for x, teken in enumerate(rij):
            if teken == "@":
                return x, y
    return None
Stap 3

Beweeg de speler

Controleer muren en kisten voordat je verplaatst.

python
def beweeg(bord, dx, dy):
    x, y = vind_speler(bord)
    nx, ny = x + dx, y + dy
    if bord[ny][nx] == "#":
        return bord
    if bord[ny][nx] == "$":
        kx, ky = nx + dx, ny + dy
        if bord[ky][kx] in "#$":
            return bord
        bord[ky] = bord[ky][:kx] + "$" + bord[ky][kx + 1:]
    bord[y] = bord[y][:x] + " " + bord[y][x + 1:]
    bord[ny] = bord[ny][:nx] + "@" + bord[ny][nx + 1:]
    return bord
