Dubbele bestanden vinden

Vind dubbele bestanden met hashes en verwijder ze veilig.

1 Waar gaat dit over?

Je leert bestanden groeperen op grootte en hash. Je bouwt een dry-run en verwijdert pas na bevestiging, zodat je nooit per ongeluk data verliest.

2 Wat leer je?

hashlibpathlibdictdry-run

3 Stap voor stap

Stap 1

Groepeer op grootte

Bestanden met een andere grootte kunnen nooit identiek zijn.

python
from pathlib import Path
from collections import defaultdict

map = Path("documenten")
op_grootte = defaultdict(list)

for bestand in map.rglob("*"):
    if bestand.is_file():
        op_grootte[bestand.stat().st_size].append(bestand)
Stap 2

Hash alleen kansrijke groepen

Dit bespaart tijd bij grote mappen.

python
import hashlib

def bestand_hash(pad):
    hasher = hashlib.sha256()
    with pad.open("rb") as bestand:
        for blok in iter(lambda: bestand.read(65536), b""):
            hasher.update(blok)
    return hasher.hexdigest()

op_hash = defaultdict(list)
for bestanden in op_grootte.values():
    if len(bestanden) > 1:
        for bestand in bestanden:
            op_hash[bestand_hash(bestand)].append(bestand)
Stap 3

Toon de dubbelen

Print elke groep met dezelfde inhoud.

python
dubbel = {h: paden for h, paden in op_hash.items() if len(paden) > 1}
for paden in dubbel.values():
    print("Dubbel:")
    for pad in paden:

Stap 4

Verwijder alleen na bevestiging

Houd altijd één bestand per groep.

python
for paden in dubbel.values():
    for pad in paden[1:]:
        antwoord = input(f"Verwijder {pad}? (j/n) ")
        if antwoord.lower() == "j":
            pad.unlink()
