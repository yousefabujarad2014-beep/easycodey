1 Waar gaat dit over?

Je leert een doolhof als grid voorstellen en zoeken met een stack. Dit is een klassiek algoritme dat je ook buiten games gebruikt.

3 Stap voor stap

Stap 1

Maak een doolhof

Een # is een muur en een punt is een vrije plek.

python
doolhof = [
    "#########",
    "#S..#...#",
    "#.#.#.#.#",
    "#.#...#.#",
    "#.#####.#",
    "#.......#",
    "#########",
]
Stap 2

Zoek de buurvakjes

Vanuit een positie kun je naar boven, onder, links en rechts.

python
def buren(positie):
    x, y = positie
    for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        nx, ny = x + dx, y + dy
        if doolhof[ny][nx] != "#":
            yield (nx, ny)
Stap 3

Zoek met een stack

Depth-first search probeert steeds een nieuwe buur. Houd bezochte vakjes bij.

python
start = (1, 1)
doel = (7, 5)
stack = [start]
bezocht = {start}
vorige = {}

while stack:
    huidig = stack.pop()
    if huidig == doel:
        break

    for buur in buren(huidig):
        if buur not in bezocht:
            bezocht.add(buur)
            vorige[buur] = huidig
            stack.append(buur)

pad = []
stap = doel
while stap != start:
    pad.append(stap)
    stap = vorige[stap]
pad.append(start)
print("Pad:", list(reversed(pad)))

4 Tips

  • Print het pad in het doolhof.
  • Probeer daarna BFS voor de kortste route.
