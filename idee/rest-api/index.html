🔌 REST API voor taken

Bouw een JSON-API die je met fetch kunt gebruiken.

Dit is de app-weergave. Speel de demo of kies ⌨ Gebruik dit idee voor alle code en uitleg.

1 Waar gaat dit over?

Je maakt een API met GET, POST, PUT en DELETE. Je leert statuscodes, JSON-antwoorden en het scheiden van data en presentatie.

2 Wat leer je?

flaskjsonhttpcrud

3 Stap voor stap

Stap 1

Maak een JSON-endpoint

Flask zet een dictionary automatisch om naar JSON.

python
from flask import Flask, jsonify
app = Flask(__name__)

taken = [{"id": 1, "titel": "Leren", "klaar": False}]

@app.get("/api/taken")
def lijst():
    return jsonify(taken)
Stap 2

Voeg een taak toe

Lees JSON uit het verzoek en geef een 201-status terug.

python
@app.post("/api/taken")
def toevoegen():
    data = request.get_json(silent=True) or {}
    titel = str(data.get("titel", "")).strip()
    if not titel:
        return jsonify({"fout": "titel ontbreekt"}), 400

    taak = {"id": len(taken) + 1, "titel": titel, "klaar": False}
    taken.append(taak)
    return jsonify(taak), 201
Stap 3

Werk een taak bij

Met PUT vervang je de velden van een bestaande taak.

python
@app.put("/api/taken/<int:taak_id>")
def bijwerken(taak_id):
    taak = next((t for t in taken if t["id"] == taak_id), None)
    if not taak:
        return jsonify({"fout": "niet gevonden"}), 404

    data = request.get_json(silent=True) or {}
    taak["titel"] = str(data.get("titel", taak["titel"]))
    taak["klaar"] = bool(data.get("klaar", taak["klaar"]))
    return jsonify(taak)
Stap 4

Verwijder een taak

DELETE geeft vaak 204 terug: gelukt, maar geen inhoud.

python
@app.delete("/api/taken/<int:taak_id>")
def verwijderen(taak_id):
    global taken
    taken = [t for t in taken if t["id"] != taak_id]
    return "", 204
Stap 5

Test met fetch

Vanuit de browser kun je de API testen zonder extra tool.

python
fetch("/api/taken")
  .then((response) => response.json())
  .then((data) => console.log(data));

4 Tips

  • Test elke statuscode: 200, 201, 400, 404 en 204.
  • Een echte API gebruikt een database en authenticatie.
