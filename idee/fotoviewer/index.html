1 Waar gaat dit over?

Je leert Pillow gebruiken om afbeeldingen te schalen, en je bouwt een eenvoudige gallerij met navigatie.

3 Stap voor stap

Stap 1

Installeer Pillow

Pillow is de standaardbibliotheek voor afbeeldingen in Python.

python

from PIL import Image, ImageTk
Stap 2

Laad een afbeelding

ImageTk maakt van een afbeelding een widget die tkinter begrijpt.

python
import tkinter as tk
from PIL import Image, ImageTk

venster = tk.Tk()
label = tk.Label(venster)
label.pack()

foto = Image.open("foto.jpg")
foto.thumbnail((800, 500))
beeld = ImageTk.PhotoImage(foto)
label.config(image=beeld)
label.image = beeld

venster.mainloop()
Stap 3

Lees een hele map

Sorteer de bestanden zodat de volgorde voorspelbaar is.

python
from pathlib import Path

EXTENSIES = {".jpg", ".jpeg", ".png", ".gif", ".webp"}
fotos = sorted(p for p in Path(".").iterdir() if p.suffix.lower() in EXTENSIES)

index = 0
Stap 4

Toon de volgende foto

Verhoog de index en houd hem binnen de lijst.

python
def volgende():
    global index, beeld
    if not fotos:
        return
    index = (index + 1) % len(fotos)
    foto = Image.open(fotos[index])
    foto.thumbnail((800, 500))
    beeld = ImageTk.PhotoImage(foto)
    label.config(image=beeld)
    label.image = beeld

tk.Button(venster, text="Volgende", command=volgende).pack()
Stap 5

Toon de bestandsnaam

Een label met de naam maakt de viewer af.

python
naam = tk.Label(venster, text=str(fotos[index].name))
naam.pack()
