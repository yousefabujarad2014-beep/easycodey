Weervenster

🪟 GUI 🎚 Gemiddeld ⏱ 75 min 5 stappen

Haal het weer op en toon het in een eigen venster.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.
Moet je iets typen? Vraagt dit project om invoer, dan verschijnt bovenaan je scherm een venster met de vraag en een tekstvak. Typ daar je antwoord en druk op Enter.

1 Waar gaat dit over?

Je combineert tkinter met requests. Je leert een API aanroepen, JSON lezen en het resultaat netjes tonen.

2 Wat leer je?

tkinterrequestsjsonthreading

3 Stap voor stap

Stap 1

Bouw het venster

Een titel, een knop en een tekstvak zijn genoeg.

python
import tkinter as tk

venster = tk.Tk()
venster.title("Weer")

titel = tk.Label(venster, text="Weer in Amsterdam", font=("Segoe UI", 18, "bold"))
titel.pack(padx=20, pady=12)

uitvoer = tk.Label(venster, text="Klik op vernieuwen", font=("Segoe UI", 14))
uitvoer.pack(padx=20, pady=12)

venster.mainloop()
Stap 2

Haal de gegevens op

Open-Meteo heeft geen sleutel nodig. Gebruik een korte time-out.

python
import requests

def haal_weer():
    url = "https://api.open-meteo.com/v1/forecast"
    params = {"latitude": 52.37, "longitude": 4.89, "current": "temperature_2m,wind_speed_10m"}
    response = requests.get(url, params=params, timeout=10)
    response.raise_for_status()
    return response.json()["current"]
Stap 3

Werk de labels bij

Doe het netwerkverzoek in een thread, anders bevriest het venster.

python
import threading

def vernieuw():
    uitvoer.config(text="Laden...")
    threading.Thread(target=laad, daemon=True).start()

def laad():
    try:
        data = haal_weer()
        tekst = f"{data['temperature_2m']} °C, wind {data['wind_speed_10m']} km/u"
    except Exception:
        tekst = "Weer niet beschikbaar"
    uitvoer.config(text=tekst)
Stap 4

Koppel de knop

Een knop start het vernieuwen.

python
tk.Button(venster, text="Vernieuwen", command=vernieuw).pack(pady=(0, 16))
