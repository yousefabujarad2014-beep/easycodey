🧬 Game of Life

Simuleer cellen die leven, sterven en geboren worden.

Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Conway's Game of Life is een grid met simpele regels die verrassend complexe patronen maakt. Je leert 2D-lijsten en buren tellen.

2 Wat leer je?

2D-lijstenburensimulatieprint

3 Stap voor stap

Stap 1

Maak een startgrid

Een paar levende cellen is genoeg om te beginnen.

python
grootte = 12
grid = [[0 for _ in range(grootte)] for _ in range(grootte)]
grid[5][5] = grid[5][6] = grid[5][7] = 1

for rij in grid:
    print("".join("█" if cel else "·" for cel in rij))
Stap 2

Tel de levende buren

Elke cel kijkt naar de acht omliggende cellen.

python
def buren(rij, kolom):
    totaal = 0
    for dr in (-1, 0, 1):
        for dk in (-1, 0, 1):
            if dr == 0 and dk == 0:
                continue
            r, k = rij + dr, kolom + dk
            if 0 <= r < grootte and 0 <= k < grootte:
                totaal += grid[r][k]
    return totaal
Stap 3

Bereken de volgende generatie

Pas de drie regels toe en print het nieuwe grid.

python
def volgende():
    nieuw = [[0] * grootte for _ in range(grootte)]
    for rij in range(grootte):
        for kolom in range(grootte):
            aantal = buren(rij, kolom)
            if grid[rij][kolom] == 1 and aantal in (2, 3):
                nieuw[rij][kolom] = 1
            elif grid[rij][kolom] == 0 and aantal == 3:
                nieuw[rij][kolom] = 1
    return nieuw

grid = volgende()
for rij in grid:
    print("".join("█" if cel else "·" for cel in rij))

4 Tips

  • Begin met een blok, een knipperlicht en een glider.
  • Maak een oneindig grid met wrap-around randen.
