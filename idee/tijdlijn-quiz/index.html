Tijdlijn-quiz

🎓 Onderwijs 🎚 Gemiddeld ⏱ 60 min 5 stappen

Zet historische gebeurtenissen in de juiste volgorde.

1 Waar gaat dit over?

Je leert data sorteren, jaartallen vergelijken en een quiz maken. Je kunt dezelfde techniek gebruiken voor biologie of aardrijkskunde.

2 Wat leer je?

sorterenlijstengeschiedenisquiz

3 Stap voor stap

Stap 1

Verzamel gebeurtenissen

Elke gebeurtenis heeft een jaar en een beschrijving.

python
gebeurtenissen = [
    ("Uitvinding van de telefoon", 1876),
    ("Eerste maanlanding", 1969),
    ("Uitvinding van de boekdrukkunst", 1440),
    ("Eerste computer", 1946),
]
Stap 2

Sorteer op jaar

Sorted met een key sorteert tuples op de tweede waarde.

python
juist = sorted(gebeurtenissen, key=lambda paar: paar[1])
for naam, jaar in juist:
    print(jaar, naam)
Stap 3

Maak een sleepvraag

Toon de gebeurtenissen in willekeurige volgorde.

python
import random

door elkaar = gebeurtenissen[:]
random.shuffle(door elkaar)
for nummer, (naam, jaar) in enumerate(door elkaar, start=1):
    print(nummer, naam)
Stap 4

Controleer de volgorde

Vraag de gebruiker om de nummers in de juiste volgorde.

python
antwoord = input("Geef de nummers van oud naar nieuw, gescheiden door komma's: ")
gekozen = [door elkaar[int(n) - 1] for n in antwoord.split(",")]
print("Goed!" if gekozen == juist else "Niet helemaal.")
Stap 5

Voeg uitleg toe

Bij elke gebeurtenis hoort een korte context.

python
uitleg = {
    "Eerste maanlanding": "Apollo 11 landde in 1969 op de maan.",
}
for naam, jaar in juist:
    print(f"{jaar}: {naam} - {uitleg.get(naam, '')}")

4 Tips

  • Test met drie gebeurtenissen voordat je er tien toevoegt.
  • Controleer jaartallen met een betrouwbare bron.
