Bouw een kleine website die het actuele weer toont.

Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Je maakt een Flask-pagina die live weerdata ophaalt bij Open-Meteo. Je leert routes, API's aanroepen en JSON omzetten naar HTML.

2 Wat leer je?

flaskrequestsjsonhtml

3 Stap voor stap

Stap 1

Start een Flask-pagina

Flask is een klein Python-webframework. Deze route geeft een eenvoudige pagina terug.

python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "<h1>Mijn weer-site</h1>"

app.run(debug=True)
Stap 2

Haal de temperatuur op

Open-Meteo is gratis en vraagt geen sleutel. Met requests haal je JSON op.

python
import requests

url = "https://api.open-meteo.com/v1/forecast"
params = {"latitude": 52.37, "longitude": 4.89, "current": "temperature_2m"}
data = requests.get(url, params=params, timeout=10).json()

print(data["current"]["temperature_2m"])
Stap 3

Toon het weer op de pagina

Combineer de route en de API. Vang netwerkfouten op zodat je site niet crasht.

python
@app.route("/")
def home():
    try:
        data = requests.get(url, params=params, timeout=10).json()
        temperatuur = data["current"]["temperature_2m"]
        return f"<h1>{temperatuur} °C in Amsterdam</h1>"
    except Exception:
        return "<h1>Weer tijdelijk niet beschikbaar</h1>"

4 Tips

  • Test je route eerst zonder API en voeg daarna pas de fetch toe.
  • Gebruik een cache of sla de laatste meting op als je de API niet te vaak wilt aanroepen.
