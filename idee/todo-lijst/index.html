To-do lijst in de terminal

🧰 Handige tools 🎚 Beginner ⏱ 45 min 5 stappen

Een takenlijst die je kunt bekijken, toevoegen en verwijderen — en die blijft bestaan.

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.
Moet je iets typen? Vraagt dit project om invoer, dan verschijnt bovenaan je scherm een venster met de vraag en een tekstvak. Typ daar je antwoord en druk op Enter.

1 Waar gaat dit over?

Bouw een klein programma waarmee je taken beheert. Je leert een menu maken met een while-loop, werken met lijsten en uiteindelijk je taken opslaan in een JSON-bestand, zodat ze niet verdwijnen als je stopt.

2 Wat leer je?

listsenumerate()whilejsonbestanden

3 Stap voor stap

Stap 1

Maak een menu dat blijft draaien

Een while True-loop toont steeds hetzelfde menu. Met break stop je het programma. Zo werkt bijna elke terminal-app.

python
taken = []

while True:
    print()
    print("1. Taken bekijken")
    print("2. Taak toevoegen")
    print("3. Stoppen")
    keuze = input("Kies: ")

    if keuze == "3":
        print("Tot de volgende keer!")
        break
Stap 2

Toon de taken met een nummer

enumerate() geeft bij elk item ook een nummer. Met start=1 begin je bij 1 in plaats van 0, dat leest prettiger.

python
if keuze == "1":
    if not taken:
        print("Je lijst is nog leeg.")
    else:
        for nummer, taak in enumerate(taken, start=1):
            print(nummer, "-", taak)
Stap 3

Voeg een taak toe

Vraag om de tekst en voeg die toe met append(). Een lege invoer sla je over, anders krijg je lege regels in je lijst.

python
if keuze == "2":
    nieuwe_taak = input("Wat wil je doen? ").strip()
    if nieuwe_taak:
        taken.append(nieuwe_taak)
        print("Toegevoegd!")
Stap 4

Verwijder een taak

De speler kiest een nummer. In Python begint een lijst bij 0, dus trek je 1 af. Controleer eerst of het nummer wel bestaat.

python
if keuze == "4":
    nummer = int(input("Welk nummer verwijderen? "))
    if 1 <= nummer <= len(taken):
        verwijderd = taken.pop(nummer - 1)
        print("Verwijderd:", verwijderd)
    else:
        print("Dat nummer bestaat niet.")
Stap 5

Bewaar de taken in een bestand

Met json.dump() schrijf je de lijst naar een bestand en met json.load() lees je hem terug. Bij de start van je programma laad je de lijst, zodat je verder kunt waar je gebleven was.

python
import json
from pathlib import Path

bestand = Path("taken.json")

if bestand.exists():
    taken = json.loads(bestand.read_text(encoding="utf-8"))
else:
    taken = []

# ... na elke wijziging:
bestand.write_text(json.dumps(taken, indent=2, ensure_ascii=False), encoding="utf-8")

4 Tips

  • Gebruik strip() op invoer zodat spaties aan het begin en eind verdwijnen.
  • Voeg een optie 'klaar' toe met een aparte lijst voor afgeronde taken.
  • Maak van de menu-acties losse functies zodra je code langer wordt.
