Weer-app met een echte API

1 Waar gaat dit over?

Je leert hoe je met een API praat: een verzoek sturen, JSON terugkrijgen en de juiste velden gebruiken. We gebruiken Open-Meteo, een gratis weer-API waarvoor je geen account nodig hebt.

3 Stap voor stap

Stap 1

Zoek de coördinaten van een stad

Open-Meteo heeft een aparte zoek-API. Stuur de stadsnaam mee als parameter en bekijk wat er terugkomt. Print de JSON eerst volledig, dan zie je de structuur.

python
import requests

plaats = input("Voor welke stad? ")

url = "https://geocoding-api.open-meteo.com/v1/search"
params = {"name": plaats, "count": 1, "language": "nl", "format": "json"}

data = requests.get(url, params=params, timeout=10).json()
print(data)
Stap 2

Haal de juiste gegevens eruit

De API geeft een lijst results terug. Als die leeg is, bestaat de stad niet. Anders pak je het eerste resultaat met naam, land en coördinaten.

python
if "results" not in data:
    print("Ik kon die plaats niet vinden.")
else:
    plek = data["results"][0]
    print(plek["name"], "-", plek["country"])
    print("Breedte:", plek["latitude"])
    print("Lengte:", plek["longitude"])
Stap 3

Vraag het weer op

Met de coördinaten vraag je het actuele weer op. De parameter current bepaalt welke velden je terugkrijgt.

python
weer_url = "https://api.open-meteo.com/v1/forecast"
weer_params = {
    "latitude": plek["latitude"],
    "longitude": plek["longitude"],
    "current": "temperature_2m,wind_speed_10m,weather_code",
}

weer = requests.get(weer_url, params=weer_params, timeout=10).json()
print(weer["current"])
Stap 4

Maak de uitvoer leesbaar

De weercode is een getal. Met een kleine functie zet je die om naar gewone taal. Daarna print je één nette zin.

python
def beschrijf(code):
    if code == 0:
        return "zonnig"
    if code in (1, 2, 3):
        return "half bewolkt"
    if code in (45, 48):
        return "mistig"
    if code in (61, 63, 65):
        return "regen"
    return "wisselvallig"


nu = weer["current"]
temperatuur = nu["temperature_2m"]
wind = nu["wind_speed_10m"]

print(f"Het is {temperatuur} °C en {beschrijf(nu['weather_code'])}.")
print(f"De wind waait met {wind} km/u.")
Stap 5

Vang netwerkfouten op

Een API kan traag zijn of offline. Met try/except voorkom je dat je programma crasht. Geef een duidelijke melding en stop netjes.

python
try:
    data = requests.get(url, params=params, timeout=10).json()
except requests.RequestException:
    print("Geen internet of de weer-dienst is niet bereikbaar.")
    raise SystemExit

4 Tips

  • Print de JSON één keer als je niet weet welk veld je nodig hebt.
  • Gebruik altijd een timeout, anders kan je script eindeloos wachten.
  • Open-Meteo vraagt geen sleutel; veel andere API's wel. Bewaar zo'n sleutel nooit in je code.
