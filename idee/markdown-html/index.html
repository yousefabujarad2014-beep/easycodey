Markdown naar HTML

🧰 Handige tools 🎚 Gemiddeld ⏱ 50 min 5 stappen

Zet een eenvoudig Markdown-bestand om naar een webpagina.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert hoe tekstverwerking werkt met reguliere expressies. Je leest een .md-bestand, vervangt koppen en vetgedrukte tekst door HTML en schrijft een complete webpagina weg.

2 Wat leer je?

reregexPathtekstverwerkingHTML

3 Stap voor stap

Stap 1

Lees een Markdown-bestand

Maak een bestand notitie.md met een paar regels tekst. Path leest het bestand in één keer als string.

python
from pathlib import Path

tekst = Path("notitie.md").read_text(encoding="utf-8")
print(tekst)
Stap 2

Vervang koppen

Met re.sub() vervang je een patroon. De vlag re.MULTILINE zorgt dat ^ aan het begin van elke regel matcht. De \1 in de vervanging is de tekst tussen haakjes.

python
import re

tekst = re.sub(r"^### (.+)$", r"<h3>\1</h3>", tekst, flags=re.MULTILINE)
tekst = re.sub(r"^## (.+)$", r"<h2>\1</h2>", tekst, flags=re.MULTILINE)
tekst = re.sub(r"^# (.+)$", r"<h1>\1</h1>", tekst, flags=re.MULTILINE)

print(tekst)
Stap 3

Maak tekst vet

Twee sterretjes rond tekst wordt <strong>. Het vraagteken in (.+?) zorgt dat de match zo kort mogelijk is, zodat twee vetgedrukte stukken op één regel niet samensmelten.

python
tekst = re.sub(r"\*\*(.+?)\*\*", r"<strong>\1</strong>", tekst)

tekst = re.sub(r"^- (.+)$", r"<li>\1</li>", tekst, flags=re.MULTILINE)

print(tekst)
Stap 4

Maak er een complete pagina van

Plak de omgezette tekst tussen HTML-tags en schrijf het resultaat naar een .html-bestand. Open dat bestand daarna in je browser.

python
html = f"""<!DOCTYPE html>
<html lang="nl">
<head>
  <meta charset="utf-8">
  <title>Mijn notitie</title>
  <style>
    body {{ max-width: 700px; margin: 40px auto; font-family: sans-serif; }}
  </style>
</head>
<body>
{tekst}
</body>
</html>"""

Path("notitie.html").write_text(html, encoding="utf-8")
print("Klaar! Open notitie.html in je browser.")
Stap 5

Test met lastige tekst

Probeer koppen, vetgedrukte woorden en lege regels door elkaar. Reguliere expressies zijn krachtig, maar je moet randgevallen testen. Voor serieus werk gebruik je de markdown-bibliotheek.

python
# Alternatief: gebruik een bestaande bibliotheek
# pip install markdown

import markdown

md = Path("notitie.md").read_text(encoding="utf-8")
html = markdown.markdown(md)

Path("notitie.html").write_text(html, encoding="utf-8")

4 Tips

  • Begin met één soort opmaak tegelijk; test na elke toevoeging.
  • Gebruik een online regex-tester om je patronen te controleren.
  • Voor productiegebruik is de markdown-bibliotheek betrouwbaarder dan zelf schrijven.
