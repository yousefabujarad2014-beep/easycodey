1 Waar gaat dit over?

Met pygame maak je een klein arcadespel. Je leert game loops, toetsenbordinvoer, botsingen en het tekenen van vormen.

2 Wat leer je?

pygamegame loopcollisionklassen

3 Stap voor stap

Stap 1

Start een pygame-venster

Pygame tekent alles in een loop. De klok houdt de snelheid stabiel.

python
import pygame

pygame.init()
scherm = pygame.display.set_mode((800, 600))
klok = pygame.time.Clock()
loopt = True

while loopt:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            loopt = False

    scherm.fill((10, 12, 20))
    pygame.display.flip()
    klok.tick(60)

pygame.quit()
Stap 2

Teken en bestuur het schip

Houd de positie bij en pas die aan op basis van ingedrukte toetsen.

python
schip_x, schip_y = 400, 500
snelheid = 6

toetsen = pygame.key.get_pressed()
if toetsen[pygame.K_LEFT]:
    schip_x -= snelheid
if toetsen[pygame.K_RIGHT]:
    schip_x += snelheid

pygame.draw.polygon(scherm, (120, 200, 255), [
    (schip_x, schip_y - 18),
    (schip_x - 14, schip_y + 14),
    (schip_x + 14, schip_y + 14)
])
Stap 3

Laat rotsen vallen en test botsingen

Beweeg de rotsen naar beneden en vergelijk de afstand met het schip.

python
import random

rotsen = [[random.randint(0, 780), 0] for _ in range(6)]

for rots in rotsen:
    rots[1] += 3
    pygame.draw.circle(scherm, (180, 180, 190), (rots[0], rots[1]), 18)

    afstand = ((rots[0] - schip_x) ** 2 + (rots[1] - schip_y) ** 2) ** 0.5
    if afstand < 30:
        print("Botsing!")
        loopt = False

4 Tips

  • Begin met één rots en voeg er daarna meer toe.
  • Gebruik een lijst met dictionaries voor alle rotsen.
