Afbeeldingen verkleinen

Verklein een hele map foto's in één keer.

1 Waar gaat dit over?

Je leert Pillow gebruiken voor batchverwerking. Je maakt een kopieermap en houdt de originele bestanden veilig.

2 Wat leer je?

pillowbatchafbeeldingenmappen

3 Stap voor stap

Stap 1

Kies een map

Lees alleen afbeeldingen en maak een uitvoermap.

python
from pathlib import Path
from PIL import Image

bron = Path("fotos")
doel = Path("verkleind")
doel.mkdir(exist_ok=True)

EXTENSIES = {".jpg", ".jpeg", ".png", ".webp"}
Stap 2

Verklein één afbeelding

thumbnail houdt de verhouding intact.

python
foto = Image.open("fotos/voorbeeld.jpg")
foto.thumbnail((1200, 1200))
foto.save("verkleind/voorbeeld.jpg", quality=85)
Stap 3

Verwerk de hele map

Sla fouten per bestand over.

python
for pad in bron.iterdir():
    if pad.suffix.lower() not in EXTENSIES:
        continue
    try:
        foto = Image.open(pad)
        foto.thumbnail((1200, 1200))
        foto.convert("RGB").save(doel / pad.name, quality=85)
        print("Klaar:", pad.name)
    except Exception as fout:
        print("Overgeslagen:", pad.name, fout)
Stap 4

Behoud de bestandsnaam

Gebruik dezelfde naam in de uitvoermap.

python
doel_pad = doel / pad.name
Stap 5

Toon de besparing

Vergelijk de bestandsgroottes.

python
oud = pad.stat().st_size
nieuw = (doel / pad.name).stat().st_size
print(f"{pad.name}: {oud // 1024} KB -> {nieuw // 1024} KB")

4 Tips

  • Maak altijd een kopie; verkleinen is niet omkeerbaar.
  • Test met één foto voordat je honderden bestanden verwerkt.
