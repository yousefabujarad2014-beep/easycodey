Raad het getal

🎮 Games 🎚 Beginner ⏱ 30 min 5 stappen

De computer kiest een geheim getal en jij moet het raden met hints.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

De computer kiest een geheim getal tussen 1 en 100. Jij typt een gok en krijgt te horen of je te hoog of te laag zit. Het perfecte eerste project: je leert invoer lezen, met getallen rekenen, beslissingen nemen en herhalen.

2 Wat leer je?

randominput()whileif / elif / elsef-strings

3 Stap voor stap

Stap 1

Laat Python een geheim getal kiezen

Met de module random laat je Python willekeurig kiezen. Print het getal één keer tijdens het testen, zodat je weet of je code klopt. Daarna haal je die regel weer weg.

python
import random

geheim = random.randint(1, 100)
print("Test: het geheime getal is", geheim)
Stap 2

Vraag de speler om een gok

input() geeft altijd tekst terug. Met int() maak je er een heel getal van. Test wat er gebeurt als je letters intypt — daar komen we later op terug.

python
gok = input("Raad het getal tussen 1 en 100: ")
gok = int(gok)

print("Je koos", gok)
Stap 3

Vergelijk en geef een hint

Vergelijk de gok met het geheime getal. Gebruik elif voor de tweede controle: zo wordt alleen de juiste tak uitgevoerd.

python
if gok < geheim:
    print("Te laag!")
elif gok > geheim:
    print("Te hoog!")
else:
    print("Goed geraden!")
Stap 4

Blijf herhalen tot het goed is

Een while-loop blijft vragen stellen tot de speler wint. De teller pogingen houdt bij hoeveel gokken je nodig had. Met break stop je de loop.

python
pogingen = 0

while True:
    gok = int(input("Jouw gok: "))
    pogingen += 1

    if gok < geheim:
        print("Te laag!")
    elif gok > geheim:
        print("Te hoog!")
    else:
        print(f"Goed! Je had {pogingen} pogingen nodig.")
        break
Stap 5

Vang foute invoer op

Als iemand 'abc' typt, crasht int(). Met try en except vang je die fout op en vraag je opnieuw. Zo wordt je spel pas echt speelbaar.

python
def vraag_gok():
    while True:
        try:
            return int(input("Jouw gok: "))
        except ValueError:
            print("Dat is geen getal. Probeer opnieuw.")


gok = vraag_gok()
print("Je gokte:", gok)

4 Tips

  • Test met een klein bereik, bijvoorbeeld 1 tot 10, dan vind je fouten sneller.
  • Laat de speler na afloop kiezen of die opnieuw wil spelen.
  • Beperk het aantal pogingen tot 10 voor extra spanning.
