1 Waar gaat dit over?

Je leert complexe getallen, iteraties en pixels. Je schrijft een PPM-afbeelding zonder externe bibliotheken, of gebruikt Pillow.

2 Wat leer je?

complexe getalleniteratiepixelswiskunde

3 Stap voor stap

Stap 1

Test één punt

De Mandelbrot-set herhaalt z = z² + c en kijkt of z ontsnapt.

python
def iteraties(c, maximum=50):
    z = 0
    for n in range(maximum):
        z = z * z + c
        if abs(z) > 2:
            return n
    return maximum

print(iteraties(complex(0, 0)))
Stap 2

Maak een kleur

Koppel het aantal iteraties aan een kleur.

python
def kleur(n, maximum=50):
    if n == maximum:
        return (10, 10, 15)
    deel = n / maximum
    return (int(255 * deel), int(120 * (1 - deel)), int(255 * (1 - deel)))
Stap 3

Bereken een klein beeld

Een lus over pixels is genoeg voor een eerste versie.

python
BREEDTE, HOOGTE = 240, 160
rijen = []

for y in range(HOOGTE):
    rij = []
    for x in range(BREEDTE):
        c = complex(-2.2 + 3.0 * x / BREEDTE, -1.2 + 2.4 * y / HOOGTE)
        rij.append(kleur(iteraties(c)))
    rijen.append(rij)
Stap 4

Schrijf een PPM-bestand

PPM is een simpel tekstformaat dat veel viewers openen.

python
with open("fractal.ppm", "w", encoding="ascii") as bestand:
    bestand.write(f"P3\n{BREEDTE} {HOOGTE}\n255\n")
    for rij in rijen:
        for r, g, b in rij:
            bestand.write(f"{r} {g} {b} ")
        bestand.write("\n")
Stap 5

Zoom in

Verklein het bereik rond een interessant punt.

python
# Probeer: x van -0.8 tot -0.7, y van 0.05 tot 0.15
# Meer iteraties geven meer detail, maar kosten tijd.

4 Tips

  • Begin klein: 240 bij 160 pixels is snel genoeg.
  • Verhoog het maximum aantal iteraties alleen als je meer detail nodig hebt.
