BMI-app

🪟 GUI 🎚 Beginner ⏱ 45 min 4 stappen

Bereken je BMI en toon een categorie.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.
Moet je iets typen? Vraagt dit project om invoer, dan verschijnt bovenaan je scherm een venster met de vraag en een tekstvak. Typ daar je antwoord en druk op Enter.

1 Waar gaat dit over?

Je leert invoer omzetten naar floats en een berekening tonen. Je voegt een duidelijke waarschuwing toe dat BMI een ruwe maat is.

2 Wat leer je?

tkinterfloatsberekenengezondheid

3 Stap voor stap

Stap 1

Maak de invoervelden

Vraag lengte in centimeters en gewicht in kilo's.

python
import tkinter as tk

venster = tk.Tk()
lengte = tk.Entry(venster)
gewicht = tk.Entry(venster)

lengte.pack()
gewicht.pack()

Bereken de BMI

Stap 3

Voeg een categorie toe

Gebruik de officiële grenzen als ruwe indicatie.

python
def categorie(bmi):
    if bmi < 18.5:
        return "ondergewicht"
    if bmi < 25:
        return "gezond gewicht"
    if bmi < 30:
        return "overgewicht"
    return "obesitas"
Stap 4

Toon een waarschuwing

BMI houdt geen rekening met spier massa of leeftijd.

python
