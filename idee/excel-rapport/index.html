Excel-rapport maken

🧰 Handige tools 🎚 Gemiddeld ⏱ 75 min 5 stappen

Schrijf data naar een Excel-bestand met opmaak.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert openpyxl gebruiken: werkbladen maken, cellen vullen en koppen opmaken. Je bouwt een rapport dat je direct kunt delen.

2 Wat leer je?

openpyxlexcelopmaakrapport

3 Stap voor stap

Stap 1

Maak een werkboek

Een nieuw werkboek heeft standaard één werkblad.

python
# pip install openpyxl
from openpyxl import Workbook

werkboek = Workbook()
blad = werkboek.active
blad.title = "Rapport"
Stap 2

Vul de koppen

Maak de eerste rij vet en breed.

python
koppen = ["Naam", "Cijfer", "Vak"]
for kolom, kop in enumerate(koppen, start=1):
    cel = blad.cell(row=1, column=kolom, value=kop)
    cel.font = cel.font.copy(bold=True)
Stap 3

Voeg rijen toe

Schrijf de data regel voor regel.

python
data = [
    ("Sam", 7.5, "Wiskunde"),
    ("Noa", 8.2, "Engels"),
    ("Mila", 6.9, "Biologie"),
]

for rij, waarden in enumerate(data, start=2):
    for kolom, waarde in enumerate(waarden, start=1):
        blad.cell(row=rij, column=kolom, value=waarde)
Stap 4

Maak kolommen leesbaar

Stel de breedte in op basis van de inhoud.

python
for kolom in "ABC":
    blad.column_dimensions[kolom].width = 18
Stap 5

Sla het bestand op

Open het daarna in Excel of LibreOffice.

python
werkboek.save("rapport.xlsx")
print("Klaar: rapport.xlsx")

4 Tips

  • Gebruik geen formules als je alleen waarden nodig hebt.
  • Test het bestand in de app waarin je het gaat gebruiken.
