Verdachte logins vinden

Analyseer een logbestand op mislukte inlogpogingen.

1 Waar gaat dit over?

Je leert logregels parseren, tellen per IP en een eenvoudige drempel instellen. Dit is een eerste stap richting security monitoring.

2 Wat leer je?

bestandendictparsensecurity

3 Stap voor stap

Stap 1

Maak testlogregels

Gebruik verzonnen regels met tijd, IP en resultaat.

python
regels = [
    "10:01 192.168.1.5 LOGIN FAIL",
    "10:02 192.168.1.5 LOGIN FAIL",
    "10:03 192.168.1.7 LOGIN OK",
    "10:04 192.168.1.5 LOGIN FAIL",
    "10:05 192.168.1.9 LOGIN FAIL",
]
Stap 2

Tel mislukte pogingen per IP

Splits de regel en gebruik een dictionary als teller.

python
from collections import Counter

mislukt = Counter()
for regel in regels:
    tijd, ip, actie, resultaat = regel.split()
    if resultaat == "FAIL":
        mislukt[ip] += 1

print(mislukt)
Stap 3

Stel een drempel in

Meld alleen IP's met drie of meer mislukte pogingen.

python
verdacht = {ip: aantal for ip, aantal in mislukt.items() if aantal >= 3}
print("Verdacht:", verdacht)
Stap 4

Lees een echt bestand

Gebruik foutenafhandeling voor regels die niet het verwachte formaat hebben.

python
def analyseer(pad):
    teller = Counter()
    with open(pad, encoding="utf-8") as bestand:
        for regel in bestand:
            delen = regel.split()
            if len(delen) == 4 and delen[3] == "FAIL":
                teller[delen[1]] += 1
    return teller
Stap 5

Maak een rapport

Sorteer op aantal pogingen en toon de top.

python
for ip, aantal in teller.most_common(5):
    print(f"{ip}: {aantal} mislukte pogingen")

4 Tips

  • Gebruik alleen je eigen testlogs of geanonimiseerde data.
  • Een hoog aantal mislukte logins kan ook een gebruiker zijn die zijn wachtwoord vergeet.
