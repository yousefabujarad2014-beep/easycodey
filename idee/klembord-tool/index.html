Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Je leert de klembordfuncties van tkinter gebruiken. Je bouwt een klein hulpmiddel voor veelgebruikte teksten.

2 Wat leer je?

tkinterklembordknoppentekst

3 Stap voor stap

Stap 1

Lees het klembord

tkinter kan tekst van het systeemklembord lezen.

python
import tkinter as tk

venster = tk.Tk()
venster.withdraw()

def lees_klembord():
    try:
        return venster.clipboard_get()
    except tk.TclError:
        return ""

print(lees_klembord())
Stap 2

Schrijf naar het klembord

Met clipboard_clear en clipboard_append zet je nieuwe tekst.

python
def schrijf_klembord(tekst):
    venster.clipboard_clear()
    venster.clipboard_append(tekst)
    venster.update()
Stap 3

Maak een opslag

Bewaar favorieten in een lijst en toon ze als knoppen.

python
favorieten = ["Bedankt!", "Ik kom eraan.", "Tot morgen."]

for tekst in favorieten:
    tk.Button(venster, text=tekst, command=lambda t=tekst: schrijf_klembord(t)).pack()
Stap 4

Bewaar favorieten

Sla ze op in een JSON-bestand.

python
import json
from pathlib import Path

Path("klembord.json").write_text(
    json.dumps(favorieten, ensure_ascii=False, indent=2),
    encoding="utf-8",
)
Stap 5

Toon het venster

Bij een klembordtool is een klein venster genoeg.

python
venster.deiconify()
venster.mainloop()

4 Tips

  • Test met tekst die emoji's bevat.
  • Gebruik geen klembordtool voor wachtwoorden.
