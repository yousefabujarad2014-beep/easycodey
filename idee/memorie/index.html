Memorie

Draai kaartjes om en vind alle paren.

1 Waar gaat dit over?

Je bouwt een tekstversie van memorie. De computer schudt een lijst met paren en jij draait steeds twee kaartjes om. Je leert lijsten, random.shuffle() en het vergelijken van waarden.

2 Wat leer je?

listsrandom.shuffleforfuncties

3 Stap voor stap

Stap 1

Maak een geschudde stapel

Bouw een lijst met elk symbool twee keer en schud hem. Zo liggen de paren willekeurig door elkaar.

python
import random

symbolen = ["A", "B", "C", "D"]
kaarten = symbolen * 2
random.shuffle(kaarten)
print(kaarten)
Stap 2

Draai twee kaarten om

Vraag de speler om twee posities. Controleer daarna of de symbolen gelijk zijn.

python
def draai(kaarten, a, b):
    print(f"Kaart {a}: {kaarten[a]}")
    print(f"Kaart {b}: {kaarten[b]}")
    return kaarten[a] == kaarten[b]

print(draai(kaarten, 0, 1))
Stap 3

Speel tot alle paren gevonden zijn

Houd bij welke paren al gevonden zijn en stop wanneer alles open is.

python
gevonden = set()

while len(gevonden) < len(kaarten):
    a = int(input("Eerste kaart (0-7): "))
    b = int(input("Tweede kaart (0-7): "))

    if draai(kaarten, a, b):
        gevonden.add(a)
        gevonden.add(b)
        print("Paar gevonden!")
    else:
        print("Helaas, probeer opnieuw.")

print("Alles gevonden!")

4 Tips

  • Print de stapel tijdens het testen, dan zie je of het schudden werkt.
  • Voeg een beurtenteller toe.
