Downloads automatisch sorteren

⚙️ Automatisering 🎚 Gemiddeld ⏱ 60 min 5 stappen

Sorteer je downloadmap in nette submappen.

1 Waar gaat dit over?

Je leert bestanden verplaatsen op basis van hun extensie. Je bouwt eerst een dry-run, zodat je ziet wat er zou gebeuren voordat er iets verandert.

2 Wat leer je?

pathlibshutilextensiesdry-run

3 Stap voor stap

Stap 1

Bepaal de doelmap

Een dictionary koppelt extensies aan mapnamen.

python
from pathlib import Path

DOELEN = {
    ".png": "Afbeeldingen",
    ".jpg": "Afbeeldingen",
    ".pdf": "Documenten",
    ".docx": "Documenten",
    ".zip": "Archieven",
    ".mp3": "Audio",
}
Stap 2

Lees de bestanden

Itereer over de map en sla alleen bestanden over.

python
downloads = Path.home() / "Downloads"

for bestand in downloads.iterdir():
    if bestand.is_file():
        print(bestand.name, bestand.suffix.lower())
Stap 3

Maak een dry-run

Print wat je zou doen zonder iets te verplaatsen.

python
def plan(bestand):
    mapnaam = DOELEN.get(bestand.suffix.lower(), "Overig")
    return downloads / mapnaam / bestand.name

for bestand in downloads.iterdir():
    if bestand.is_file():
        print(f"{bestand.name} -> {plan(bestand)}")
Stap 4

Verplaats echt

Maak de doelmap aan en verplaats het bestand.

python
import shutil

def verplaats(bestand):
    doel = plan(bestand)
    doel.parent.mkdir(exist_ok=True)
    shutil.move(str(bestand), str(doel))

for bestand in downloads.iterdir():
    if bestand.is_file() and bestand.suffix.lower() in DOELEN:
        verplaats(bestand)
Stap 5

Beveilig tegen dubbele namen

Voeg een nummer toe als de naam al bestaat.

python
def vrije_naam(doel):
    if not doel.exists():
        return doel
    for nummer in range(1, 1000):
        kandidaat = doel.with_name(f"{doel.stem}-{nummer}{doel.suffix}")
        if not kandidaat.exists():
            return kandidaat
    raise RuntimeError("Geen vrije naam gevonden")

4 Tips

  • Test eerst op een tijdelijke map met nepbestanden.
  • Sla bestanden die je niet herkent over in plaats van ze te verplaatsen.
