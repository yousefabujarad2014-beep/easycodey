3 Stap voor stap

Stap 1

Maak drie torens

De eerste toren bevat alle schijven.

torens = [list(range(4, 0, -1)), [], []]
Stap 2

Controleer een zet

Je mag alleen een kleinere schijf op een grotere leggen.

python
def mag_verplaatsen(van, naar):
    if not torens[van]:
        return False
    if not torens[naar]:
        return True
    return torens[van][-1] < torens[naar][-1]
Stap 3

Los recursief op

Verplaats n-1 schijven, dan de grootste, dan weer n-1.

python
def hanoi(n, van, naar, hulp):
    if n == 0:
        return
    hanoi(n - 1, van, hulp, naar)
    print(f"Verplaats schijf {n} van {van} naar {naar}")
    hanoi(n - 1, hulp, naar, van)

hanoi(4, 0, 2, 1)
Stap 4

Tel de zetten

Het minimum aantal zetten is 2^n - 1.

python
print("Minimaal", 2 ** 4 - 1, "zetten")

4 Tips

  • Teken de torens na elke zet om het algoritme te begrijpen.
  • Begin met drie schijven.
