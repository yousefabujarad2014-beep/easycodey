🎾 Vallende bal

Simuleer een stuiterende bal met zwaartekracht.

Dit is de app-weergave. Speel de demo of kies ⌨ Gebruik dit idee voor alle code en uitleg.

1 Waar gaat dit over?

Je modelleert positie en snelheid in kleine stappen. Zo leer je hoe simulaties met een loop werken.

2 Wat leer je?

whilefloatsimulatieprint

3 Stap voor stap

Stap 1

Start de simulatie

De bal begint hoog met snelheid nul.

python
hoogte = 100.0
snelheid = 0.0
zwaartekracht = -9.81
dt = 0.1
Stap 2

Werk de beweging bij

Elke stap verandert de snelheid en daarna de hoogte.

python
for _ in range(50):
    snelheid += zwaartekracht * dt
    hoogte += snelheid * dt
    print(round(hoogte, 2))
Stap 3

Laat de bal stuiteren

Keer de snelheid om bij de grond en verlies een beetje energie.

python
for _ in range(300):
    snelheid += zwaartekracht * dt
    hoogte += snelheid * dt

    if hoogte <= 0:
        hoogte = 0
        snelheid = -snelheid * 0.8

    if int(_) % 10 == 0:
        print(round(hoogte, 2))

4 Tips

  • Maak een grafiek van de hoogte.
  • Voeg luchtweerstand toe.
