📷 Fotogalerij

Upload foto's en toon ze in een galerij.

Dit is de app-weergave. Speel de demo of kies ⌨ Gebruik dit idee voor alle code en uitleg.

1 Waar gaat dit over?

Je leert bestanden uploaden, bestandsnamen veilig maken en afbeeldingen tonen. Dit is een basis voor elke media-app.

2 Wat leer je?

flaskuploadbestandenhtml

3 Stap voor stap

Stap 1

Maak een uploadformulier

Een formulier met enctype multipart verstuurt bestanden.

python
@app.route("/")
def home():
    return """
      <form method="post" enctype="multipart/form-data">
        <input type="file" name="foto" accept="image/*" required>
        <button>Uploaden</button>
      </form>
    """
Stap 2

Ontvang het bestand

Controleer de extensie en sla het op in een uploads-map.

python
from werkzeug.utils import secure_filename
from pathlib import Path

UPLOAD = Path("uploads")
UPLOAD.mkdir(exist_ok=True)
TOEGESTAAN = {".png", ".jpg", ".jpeg", ".webp", ".gif"}

@app.post("/")
def upload():
    foto = request.files.get("foto")
    if not foto or not foto.filename:
        return "Geen bestand", 400

    naam = secure_filename(foto.filename)
    if Path(naam).suffix.lower() not in TOEGESTAAN:
        return "Alleen afbeeldingen", 400

    foto.save(UPLOAD / naam)
    return redirect("/")
Stap 3

Toon de galerij

Loop over de map en maak een img-tag per bestand.

python
@app.get("/")
def galerij():
    fotos = "".join(
        f'<img src="/uploads/{foto.name}" alt="{foto.stem}" loading="lazy">'
        for foto in UPLOAD.iterdir()
        if foto.suffix.lower() in TOEGESTAAN
    )
    return f"<h1>Galerij</h1>{fotos}"
Stap 4

Serveer de afbeeldingen

Flask kan een map met statische bestanden serveren.

python
from flask import send_from_directory

@app.get("/uploads/<naam>")
def upload_bestand(naam):
    return send_from_directory(UPLOAD, naam)
Stap 5

Beperk de bestandsgrootte

Grote uploads kunnen je schijf vullen.

python
app.config["MAX_CONTENT_LENGTH"] = 5 * 1024 * 1024

4 Tips

  • Test met een kleine afbeelding.
  • Gebruik nooit de originele bestandsnaam zonder secure_filename().
