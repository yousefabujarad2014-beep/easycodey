Webscraper voor nieuwskoppen

🌐 Web 🎚 Gemiddeld ⏱ 60 min 5 stappen

Haal automatisch de nieuwste koppen van een website en bewaar ze als CSV.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert hoe een webpagina in elkaar zit en hoe je met BeautifulSoup informatie eruit haalt. We oefenen op een site die scraping toestaat. Je leert ook waarom je altijd de regels van een site moet respecteren.

2 Wat leer je?

requestsBeautifulSoupHTMLselectorsCSV

3 Stap voor stap

Stap 1

Haal een pagina op

Installeer de pakketten met pip install requests beautifulsoup4. Vraag de pagina op met een herkenbare User-Agent en een timeout.

python
import requests
from bs4 import BeautifulSoup

url = "https://news.ycombinator.com/"
headers = {"User-Agent": "EasyCodeyLeerproject/1.0 (leerproject)"}

pagina = requests.get(url, headers=headers, timeout=10)
soep = BeautifulSoup(pagina.text, "html.parser")

print(soep.title.text)
Stap 2

Zoek de juiste elementen

Open de pagina in je browser en bekijk de HTML. De koppen staan in een span met class titleline. Met select() zoek je op CSS-selector.

python
titels = soep.select(".titleline")

for titel in titels[:10]:
    print("-", titel.get_text())
Stap 3

Bewaar titel en link

Elke titel bevat een link. Met find('a') pak je die link en met ['href'] lees je het adres. Zet de resultaten in een lijst met woordenboeken.

python
koppen = []

for titel in titels[:10]:
    link = titel.find("a")
    if link:
        koppen.append({
            "titel": titel.get_text(),
            "url": link["href"],
        })

for kop in koppen:
    print(kop["titel"])
Stap 4

Schrijf de resultaten naar CSV

Met de csv-module maak je een bestand dat je in Excel of Google Sheets kunt openen. newline='' voorkomt lege regels op Windows.

python
import csv

with open("koppen.csv", "w", newline="", encoding="utf-8") as bestand:
    schrijver = csv.DictWriter(bestand, fieldnames=["titel", "url"])
    schrijver.writeheader()
    schrijver.writerows(koppen)

print("Opgeslagen in koppen.csv")
Stap 5

Respecteer de regels

Niet elke site wil dat je hem automatisch uitleest. Kijk altijd naar robots.txt en de gebruiksvoorwaarden. Doe rustig aan met verzoeken en zet geen persoonlijke gegevens in je User-Agent.

python
# Controleer eerst:
# https://news.ycombinator.com/robots.txt

# Voeg een korte pauze toe tussen verzoeken:
import time

for pagina_nummer in range(1, 4):
    print("Pagina", pagina_nummer, "ophalen...")
    time.sleep(1)  # wees vriendelijk voor de server

4 Tips

  • Websites veranderen; als je selector niet werkt, bekijk dan opnieuw de HTML.
  • Scrape geen persoonlijke data en omzeil geen inlogmuren.
  • Bewaar ruwe HTML tijdens het ontwikkelen, dan hoef je niet steeds opnieuw te laden.
