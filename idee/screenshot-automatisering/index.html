Screenshot maken

⚙️ Automatisering 🎚 Gemiddeld ⏱ 50 min 5 stappen

Maak automatisch een screenshot van je scherm.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert pyautogui gebruiken en bestanden met een datum opslaan. Handig voor het maken van lesmateriaal of het loggen van een scherm.

2 Wat leer je?

pyautoguidatetimebestandenautomatisering

3 Stap voor stap

Stap 1

Installeer pyautogui

De bibliotheek werkt op Windows, macOS en Linux met een scherm.

python
# pip install pyautogui
import pyautogui
Stap 2

Maak een screenshot

pyautogui.screenshot geeft een afbeelding terug.

python
foto = pyautogui.screenshot()
foto.save("scherm.png")
Stap 3

Voeg een tijdstempel toe

Zo krijgt elk screenshot een unieke naam.

python
from datetime import datetime

naam = datetime.now().strftime("scherm-%Y-%m-%d_%H-%M-%S.png")
pyautogui.screenshot().save(naam)
Stap 4

Maak een reeks

Wacht tussen de opnames en maak een map aan.

python
import time
from pathlib import Path

map = Path("screenshots")
map.mkdir(exist_ok=True)

for nummer in range(3):
    tijd = datetime.now().strftime("%H-%M-%S")
    pyautogui.screenshot().save(map / f"scherm-{tijd}.png")
    time.sleep(5)
Stap 5

Beperk de regio

Je kunt alleen een deel van het scherm vastleggen.

python
foto = pyautogui.screenshot(region=(0, 0, 800, 600))
foto.save("links-boven.png")

4 Tips

  • Maak geen screenshots met privégegevens.
  • Test eerst met één opname voordat je een reeks start.
