Zwaartekracht-simulatie

🔬 Wetenschap 🎚 Gemiddeld ⏱ 75 min 4 stappen

Simuleer vallende objecten met echte natuurkunde.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leert snelheid en versnelling integreren. Je vergelijkt een simulatie met de formule voor vrije val.

2 Wat leer je?

natuurkundesimulatiesnelheidgrafiek

3 Stap voor stap

Stap 1

Stel de beginwaarden in

Hoogte, snelheid en tijd beginnen bij nul.

python
hoogte = 100.0
snelheid = 0.0
tijd = 0.0
G = 9.81
dt = 0.05
Stap 2

Simuleer de val

Versnel en werk de positie bij.

python
hoogtepunten = []

while hoogte > 0:
    snelheid += G * dt
    hoogte -= snelheid * dt
    tijd += dt
    hoogtepunten.append((tijd, max(0, hoogte)))
Stap 3

Vergelijk met de formule

De theoretische valtijd is wortel van 2h/g.

python
import math

theorie = math.sqrt(2 * 100 / G)
print(f"Simulatie: {tijd:.2f} s, theorie: {theorie:.2f} s")
Stap 4

Maak een grafiek

Print een eenvoudige tekstgrafiek of gebruik matplotlib.

python
for t, h in hoogtepunten[::20]:
    print(f"{t:4.1f}s " + "#" * int(h // 5))

4 Tips

  • Kleinere tijdstappen geven een nauwkeuriger resultaat.
  • Vergelijk altijd met een handmatige berekening.
