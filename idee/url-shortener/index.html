Linkverkorter

🌐 Web 🎚 Gemiddeld ⏱ 75 min 5 stappen

Maak korte links die doorverwijzen naar een lange URL.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je bouwt een URL-shortener met een dictionary en een redirect-route. Je leert willekeurige codes maken en HTTP-redirects gebruiken.

2 Wat leer je?

flaskdictrandomredirect

3 Stap voor stap

Stap 1

Maak een korte code

Gebruik letters en cijfers om een unieke code te maken.

python
import random
import string

def maak_code(lengte=6):
    tekens = string.ascii_letters + string.digits
    return "".join(random.choice(tekens) for _ in range(lengte))

print(maak_code())
Stap 2

Bewaar de link

Een dictionary koppelt de korte code aan de lange URL.

python
links = {}

@app.route("/", methods=["GET", "POST"])
def home():
    korte_link = ""
    if request.method == "POST":
        url = request.form.get("url", "").strip()
        code = maak_code()
        links[code] = url
        korte_link = f"http://localhost:5000/{code}"
    return f"""
      <form method="post">
        <input name="url" placeholder="https://..." required>
        <button>Verkort</button>
      </form>
      <p>{korte_link}</p>
    """
Stap 3

Verwijs door

De route leest de code en stuurt de browser naar de opgeslagen URL.

python
from flask import redirect

@app.route("/<code>")
def doorsturen(code):
    url = links.get(code)
    if not url:
        return "Onbekende link", 404
    return redirect(url)
Stap 4

Valideer de URL

Controleer of de invoer met http:// of https:// begint voordat je hem opslaat.

python
from urllib.parse import urlparse

def geldige_url(url):
    parsed = urlparse(url)
    return parsed.scheme in ("http", "https") and bool(parsed.netloc)
Stap 5

Laat de dictionary zien

Een beheerpagina maakt je project makkelijker te testen.

python
@app.route("/links")
def overzicht():
    regels = "".join(f"<li>{code} → {url}</li>" for code, url in links.items())
    return f"<h1>Alle links</h1><ul>{regels}</ul>"

4 Tips

  • Gebruik geen echte wachtwoorden of privélinks in je testdata.
  • Een echte dienst zou links in een database opslaan.
