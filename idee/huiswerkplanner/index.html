🗓️ Huiswerkplanner

Plan je huiswerk op basis van deadline en moeilijkheid.

Dit is de app-weergave. Speel de demo of kies ⌨ Gebruik dit idee voor alle code en uitleg.

1 Waar gaat dit over?

Je leert datums vergelijken, taken sorteren en een weekplanning maken. Je bouwt een planner die rekening houdt met beschikbare tijd.

2 Wat leer je?

datetimesorterenplannenlijsten

3 Stap voor stap

Stap 1

Maak taken

Elke taak heeft een vak, deadline en geschatte duur.

python
from datetime import date

taken = [
    {"vak": "Wiskunde", "deadline": date(2026, 11, 12), "minuten": 60, "moeilijk": 3},
    {"vak": "Engels", "deadline": date(2026, 11, 10), "minuten": 30, "moeilijk": 1},
    {"vak": "Biologie", "deadline": date(2026, 11, 14), "minuten": 90, "moeilijk": 2},
]
Stap 2

Sorteer op urgentie

Eerst de dichtstbijzijnde deadline, daarna de moeilijkste taak.

python
vandaag = date.today()
taken.sort(key=lambda taak: (taak["deadline"] - vandaag, -taak["moeilijk"]))
Stap 3

Verdeel over dagen

Plan taken tot je dagbudget vol is.

python
DAGBUDGET = 90

planning = {}
for taak in taken:
    dagen = max(1, (taak["deadline"] - vandaag).days)
    per_dag = min(DAGBUDGET, max(15, taak["minuten"] // dagen))
    planning.setdefault(taak["deadline"].isoformat(), []).append((taak["vak"], per_dag))
Stap 4

Toon de planning

Maak een leesbare lijst per dag.

python
for dag, items in sorted(planning.items()):
    print(f"\n{dag}")
    for vak, minuten in items:
        print(f"  {vak}: {minuten} minuten")
Stap 5

Waarschuw bij te weinig tijd

Tel de benodigde minuten en vergelijk met je budget.

python
nodig = sum(taak["minuten"] for taak in taken)
beschikbaar = DAGBUDGET * 7
print("Het past." if nodig <= beschikbaar else "Je hebt te veel taken voor één week.")

4 Tips

  • Plan niet elke minuut vol; houd ruimte voor pauzes.
  • Gebruik realistische schattingen en pas ze na een dag aan.
