Portfolio-generator

🌐 Web 🎚 Gemiddeld ⏱ 90 min 5 stappen

Maak een portfolio-website uit een JSON-bestand.

▶ Speel dit idee Open in EasyCodey ⌨ Programmeer dit idee

Speel dit idee opent de app en voert het volledige programma meteen uit. Je voortgang wordt lokaal in je browser bewaard.

1 Waar gaat dit over?

Je leest projectgegevens uit JSON en genereert een complete HTML-pagina. Je leert templates, escaping en bestanden schrijven.

2 Wat leer je?

jsonhtmltemplatesbestanden

3 Stap voor stap

Stap 1

Beschrijf je projecten

Een lijst met dictionaries is makkelijk aan te passen.

python
projecten = [
    {"titel": "Weer-app", "url": "https://example.com", "tags": ["Flask", "API"]},
    {"titel": "Snake", "url": "https://example.com", "tags": ["pygame"]},
]
Stap 2

Bouw de HTML

Genereer per project een kaart met een link en tags.

python
def kaart(project):
    tags = "".join(f"<span>{tag}</span>" for tag in project["tags"])
    return f"""
      <article>
        <h2>{project['titel']}</h2>
        <p>{tags}</p>
        <a href="{project['url']}">Bekijk project</a>
      </article>
    """

inhoud = "".join(kaart(p) for p in projecten)
Stap 3

Schrijf de pagina

Met een volledige HTML-wrapper schrijf je alles naar index.html.

python
html = f"""<!DOCTYPE html>
<html lang="nl">
<head><meta charset="utf-8"><title>Mijn portfolio</title></head>
<body><h1>Mijn projecten</h1>{inhoud}</body>
</html>"""

with open("portfolio.html", "w", encoding="utf-8") as bestand:
    bestand.write(html)
Stap 4

Escape de invoer

Gebruik html.escape zodat een titel met < of > de pagina niet breekt.

python
from html import escape

titel = escape(project["titel"])
Stap 5

Lees uit JSON

Zo kun je de inhoud aanpassen zonder Python te wijzigen.

python
import json

with open("projecten.json", encoding="utf-8") as bestand:
    projecten = json.load(bestand)

4 Tips

  • Open de gegenereerde pagina in je browser en controleer alle links.
  • Houd de generator gescheiden van de data.
