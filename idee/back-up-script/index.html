💾 Back-up-script

Maak automatisch een zip-back-up van een map.

Dit is de app-weergave. Speel de demo en schakel daarna naar Code voor alle stappen en uitleg.

1 Waar gaat dit over?

Je leert zipbestanden maken, datums in bestandsnamen gebruiken en oude back-ups opruimen. Je bouwt een script dat je echt kunt plannen.

2 Wat leer je?

zipfiledatetimepathlibopschonen

3 Stap voor stap

Stap 1

Maak een zip

ZipFile schrijft een archief met alle bestanden uit een map.

python
from pathlib import Path
import zipfile

bron = Path("project")
doel = Path("back-ups") / "project.zip"
doel.parent.mkdir(exist_ok=True)

with zipfile.ZipFile(doel, "w", zipfile.ZIP_DEFLATED) as archief:
    for bestand in bron.rglob("*"):
        if bestand.is_file():
            archief.write(bestand, bestand.relative_to(bron))
Stap 2

Voeg een datum toe

Zo overschrijf je nooit per ongeluk een oude back-up.

python
from datetime import datetime

stempel = datetime.now().strftime("%Y-%m-%d_%H-%M")
doel = Path("back-ups") / f"project-{stempel}.zip"
Stap 3

Sla lege mappen over

Een zip bevat alleen bestanden, dus controleer je invoer.

python
if not any(bron.rglob("*")):
    print("De bronmap is leeg.")
Stap 4

Ruim oude back-ups op

Bewaar bijvoorbeeld de laatste tien archieven.

python
backups = sorted(Path("back-ups").glob("project-*.zip"))
for oud in backups[:-10]:
    oud.unlink()
Stap 5

Maak een restore-test

Controleer of je een bestand uit de zip kunt lezen.

python
with zipfile.ZipFile(doel) as archief:
    namen = archief.namelist()
    print(namen[:5])
    archief.extract(namen[0], "test-restore")

4 Tips

  • Test het uitpakken voordat je op het script vertrouwt.
  • Bewaar back-ups op een andere schijf of in de cloud.
