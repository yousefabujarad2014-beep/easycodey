Exoplaneet-transit

🔬 Wetenschap 🎚 Gevorderd ⏱ 2 uur 4 stappen

Simuleer een dip in het licht van een ster.

1 Waar gaat dit over?

Je leert hoe astronomen planeten vinden door helderheidsdips. Je bouwt een lichtcurve met een periodieke transit.

2 Wat leer je?

astronomielichtcurvewiskundedata

3 Stap voor stap

Stap 1

Modelleer de ster

De helderheid is bijna constant.

python
basis = 1.0
helderheid = []
Stap 2

Voeg een transit toe

Als de planeet voor de ster langs gaat, daalt de helderheid.

python
for minuut in range(0, 600):
    dip = 0.02 if 240 < minuut < 260 else 0.0
    helderheid.append(basis - dip)
Stap 3

Maak een lichtcurve

Print de waarden als een grafiek in de terminal.

python
for minuut in range(0, 600, 10):
    waarde = helderheid[minuut]
    balk = "#" * int(waarde * 40)
    print(f"{minuut:3d} {balk}")
Stap 4

Bereken de periode

Herhaal de dip en meet de afstand tussen twee dips.

python
dips = [i for i, w in enumerate(helderheid) if w < 0.99]
print("Eerste dip op minuut", dips[0])

4 Tips

  • Een echte transit is veel kleiner; dit is een vereenvoudigd model.
  • Voeg ruis toe om realistische data na te bootsen.
