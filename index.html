De offline coach staat aan. Die geeft je een stappenplan op basis van je woorden.

AI-instellingen

De AI-coach gebruikt de OpenAI-API (of een andere OpenAI-compatibele dienst). Je sleutel wordt alleen lokaal in deze browser opgeslagen en via deze server doorgestuurd.

Tip: op een gedeelde computer kun je de sleutel beter via een .env-bestand op de server zetten. Zie de README.

Probeer Python

Typ Python en klik op Uitvoeren. De eerste keer wordt Python in je browser geladen (ongeveer 10 MB). Je code wordt niet naar een server gestuurd. 

Uitvoer verschijnt hier.

Python draait via Pyodide (WebAssembly) in je browser. input() opent een invoer-pop-up. Vermijd oneindige loops; die kun je alleen stoppen door het venster te sluiten. Gebruik ▶ Speel bij een codeblok om dat stuk code direct uit te proberen.

EasyCodey als app

Zet EasyCodey op je computer of telefoon. De app krijgt een eigen icoon, opent in een eigen venster en werkt na de eerste keer ook offline. Je voortgang blijft gewoon bewaard.

  1. Chrome of Edge op de computer Klik rechtsboven in de adresbalk op het installatie-icoon, of gebruik het menu ⋮ → App installeren.
  2. Android (Chrome) Menu ⋮ → App installeren of Toevoegen aan startscherm.
  3. iPhone of iPad (Safari) Tik op Deel → Zet op beginscherm.

Zodra je browser de app kan installeren, verschijnt hieronder de knop Installeer nu. Python werkt offline nadat je het één keer hebt gebruikt. Bekijk de volledige installatie-uitleg.
